# Notes

A small web app written in Novis. It saves notes in SQLite, shows them as HTML pages and has a small JSON API.

Run these commands in this folder:

```sh
nvs serve public/index.nvs   # open http://127.0.0.1:8000/
nvs test tests/              # runs the tests
```

The page [Example apps: Notes](https://novis-lang.org/guides/example-apps/notes/) explains each file.
