# A row that names no member at all is keyed by its class instead — `§13
# Core\BigInt` — because the roster is the only claim a row makes, and a class

# prose beside one. The list **only shrinks**: registering a member and striking
# its line here are one edit, and the test fails on a stale line as loudly as on
# an unlisted one. When this file holds no keys, spec § 13 is registered whole.
