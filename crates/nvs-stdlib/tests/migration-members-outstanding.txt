# names that `nvs_stdlib::registry::CLASSES` does not declare yet. One key per
# line, spelled exactly as the table's Novis cell spells it, then the goal that
# will strike it, named by its slug: `Core\Os::pid  # net-os-signal`, read against docs/agent/goals/
# by `every_outstanding_key_names_an_owner`. That test's doc owns the column,
# and `unowned` is the answer for a member no entry on the chain builds.
#
# `tests/spec_registry_coverage.rs` owns this file, and its module doc says why it
# exists rather than the test simply failing. The list **only shrinks**: adding a
# member and striking its line here are one edit, and the test fails on a stale
# line as loudly as on an unlisted one. When this file holds no keys, every member
# the migration table promises a migrating program exists — which, with the
# table's own `Complete:` header at `yes`, is the parity program's stop condition.
#
# A key here is a member that is **owed**, never one that is refused: a PHP name
# with no Novis answer is a `dropped` or an `open` row in that table, not a
# `member` row with a spelling nothing backs.
