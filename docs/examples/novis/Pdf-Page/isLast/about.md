Checks whether a page is the last page of the document.

`isLast` returns `true` when the page number is the same as the page count. Use it in a footer
function to write something only at the end, such as a signature line. You can also use it to write
"Continued on the next page" on every other page. A document with one page is both the first page
and the last page.

**The examples below** write a note on every page except the last, put a signature line on the
last page, and show a document of one page.
