The time the script that reports a failure is allowed to take.

The other half of the same allotment, and it is a ceiling on a report rather than a budget for work.
What makes a report slow is almost never the formatting — it is the destination, a log file on a
busy disk or a socket that is not answering — so the number covers a slow write rather than a
computation.

Five seconds where nobody writes otherwise, a hundred times the slice `[limits]` keeps for a handler
running inside the request, because this one compiles and starts a script first.

It belongs to whoever runs the deployment, like the memory beside it: a program that could cut the
time its own report may take could cut it to nothing, and a report that never finishes is a failure
nobody hears about.

The example prints it beside the other three numbers it is easy to mistake it for.
