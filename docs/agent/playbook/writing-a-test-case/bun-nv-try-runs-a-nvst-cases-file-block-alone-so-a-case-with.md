- **`bun nv try` runs a `.nvst` case's `--FILE--` block alone, so a case with a `--FILE nvs.toml--` section fails with a wall of `E0319` on the TOML lines.** `tools/nv/cmd/try.ts` reads everything after `--FILE--` as one program and knows nothing of the extra file sections, and it runs the pipeline's prebuilt binary rather than one with your Rust change. Build with `cargo build` and run `target/debug/nvs.exe test <case>.nvst`, which is the runner `nv verify` itself uses. [until: gone tools/nv/cmd/try.ts:optionally]
