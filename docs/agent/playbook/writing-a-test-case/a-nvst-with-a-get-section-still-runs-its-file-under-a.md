- **A `.nvst` with a `--GET--` section still runs its file under a terminal sink, so `echo "<b>"` prints `<b>` and not `&lt;b&gt;`.** The request sections only fill `Core\Request`, and the HTML sink is attached by a real request. To test what `echo` writes under a request, put the handler under `if (Core\Env::context() == Core\Env::Context::Request)` and call `Core\Test::request(...)` in the `else`, as `tests/conformance/core/echo-in-a-request-escapes-a-string-and-writes-markup-as-it-is.nvst` does. `until: gone tests/conformance/core/echo-in-a-request-escapes-a-string-and-writes-markup-as-it-is.nvst:Core\Test::request`
