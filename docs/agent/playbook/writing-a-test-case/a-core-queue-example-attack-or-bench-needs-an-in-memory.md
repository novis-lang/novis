- **A `Core\Queue` example, attack or bench needs an in-memory SQLite block and must create the queue tables itself.** `nvs queue migrate` cannot run inside a proof, and a `[db.<name>]` block with a file `path` keeps its rows between runs, so the second run of a proof prints different counts. Put `path = ":memory:"`, `[capabilities.db] connect` and `[queue] connection`/`workers = 0` in the directory's `nvs.toml`: the queue and `Core\Db::connect` then share the one database. Copy the two `create table` texts from `docs/examples/core/Queue/status/01-check-a-new-job.nvs`. [until: gone docs/examples/core/Queue/status/nvs.toml:workers = 0]
