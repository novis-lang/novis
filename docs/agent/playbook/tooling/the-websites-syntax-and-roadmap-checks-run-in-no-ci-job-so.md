- **The website's `syntax` and `roadmap` checks run in no CI job, so a new `Core` enum, error class or `lang:` feature stays uncovered until a goal runs the whole `bun nv site --check`.** CI runs only `structure snippets stale questions prose` and `shots` (`.github/workflows/ci.yml`). Add an enum to `syntax/values/enums.mdx`'s `covers:`, an error class to `syntax/errors/error-types.mdx` with a table row, and a `lang:` feature to its Syntax page with a `<FeatureSection>`. Then `bun nv site --stamp` the page and restamp its questions. `until: gone .github/workflows/ci.yml:site --check structure snippets stale questions prose`
