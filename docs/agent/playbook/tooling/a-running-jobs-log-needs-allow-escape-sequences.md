- **While a run is going, `gh run view --job <id> --log` prints only "still in progress", and `gh api .../actions/jobs/<id>/logs` prints only "the response contains terminal escape sequences".** Neither message looks like the log, and a pipe into `grep` hides both. Pass `--allow-escape-sequences` to the `gh api` call and strip `\x1b\[[0-9;]*m` with `perl -pe`, which gives a failed job's log from `.github/workflows/ci.yml` before the run ends. `until: gone .github/workflows/ci.yml:CARGO_TERM_COLOR: always`
