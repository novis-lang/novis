- **A sweep that fails every crate's test binary and most of `tests/conformance/` at once is a build that raced something, not a regression.** The driver's sweep builds into `target/covws` and then runs from it for twenty minutes, so a hand commit or `cargo` run in the same tree during that window (here a user's `Cargo.toml` change) can leave every binary the sweep runs failing together, even crates as small as `nvs-diagnostics`. Run `bun nv verify` once before you diagnose any single crate: if it is green, the tree is fine and the retry only needs the goal's claim re-made. [until: gone tools/nv/lib/covws.ts:COVWS_TARGET]
