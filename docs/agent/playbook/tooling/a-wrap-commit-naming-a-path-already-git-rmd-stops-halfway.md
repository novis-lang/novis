- **A wrap `## commit:` that names a path already removed with `git rm` stops `--wrap` halfway.** The commits before it land, and then `git add -- <path>` fails with `pathspec did not match` after validation passed, so the all-or-nothing promise does not hold. Delete a record with `rm`, not `git rm`, before the wrap, or leave the deleted path out of the `## commit:` line; if it already happened, commit the rest by hand with `git commit -F`.
