- **A row in the mode table is not a key: `nvs.toml` refuses it at boot and `Request::get` returns `None` for it.** `deny_unknown_fields` on `nvs_config::tree::Log` refuses an unnamed key, and a default needs its own `Value::ByMode` row. Add the `tree.rs` field, the `crates/nvs-config/src/defaults.rs` row and the `default.toml` line beside `crates/nvs-config/src/mode.rs`'s row. `until: gone crates/nvs-config/src/mode.rs:pub const DERIVED`
