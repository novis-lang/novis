- **An acceptance check that fails with `multiple workspace roots found` or `failed to load manifest for workspace member` naming a path under `.agent-tmp/` is another agent's cargo probe, not the tree.** A probe that briefly adds its own scratch crate to the root `Cargo.toml`'s `members` breaks every cargo command in the tree until it is removed, so every cargo-backed check and the rustdoc gate go red at once. Run `git status --short` and check that the named path still exists; when both are clean, re-run the failed check and the gate unchanged, and delete nothing you did not write.
