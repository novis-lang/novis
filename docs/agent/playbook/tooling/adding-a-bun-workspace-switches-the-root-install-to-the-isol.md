- **Adding a Bun workspace switches the root install to the isolated layout and moves the old `node_modules` aside, and the downloaded Chromium goes with it.** A project with workspaces defaults to one `node_modules` per package, so the root's packages become links and `.local-browsers` stays in the moved-aside folder. `bunfig.toml` sets `linker = "hoisted"`. After any layout change, delete `node_modules`, run `bun install`, and reinstall the headless shell as `tools/nv/test/chromium.ts` says.
