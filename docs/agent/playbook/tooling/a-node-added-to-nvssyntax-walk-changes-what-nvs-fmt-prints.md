- **A node added to `nvs_syntax::walk` changes what `nvs fmt` prints and what `Core\Ast::parse` returns.** The formatter's indenter reads the index built from the walk, and a node whose first byte opens a line, directly under a body such as a method, is placed as a line of that body. `Attribute` starts at the attribute's name, past the `#[`, so a `#[` line still opens on its declaration. Give a new node a span that does not start a line its parent owns, then run `cargo test --test identity` and read every file it names.
