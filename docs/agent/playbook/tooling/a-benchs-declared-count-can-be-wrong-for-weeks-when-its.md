- **A bench's declared count can be wrong for weeks when its member's file never changes, and the first edit to that file makes the whole group fail at once.** A change to what the probes count, such as putting call probes around every `Core` call, re-measures only the figures that were stale at the time, so a group like `Core\BigInt` kept `// bench: calls 0` while it made 2. Before you plan a slice's re-record, run `bun nv proofs --record-perf --group '<group>'` once and set each `// bench:` line to what it measured, as its own change. `tools/nv/proofs/perf.ts` judges the declarations. `until: gone benches/members/core/BigInt/abs.nvs:// bench: calls 2`
