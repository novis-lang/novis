- **A property's or a constant's `ClassMember::span` ends before its `;`, so an edit placed at the last member's `span.end` lands inside that declaration.** A generator that inserts methods after a class's last member wrote them between `= 0` and `;` when that member was a property, and the editor offered nothing, because the rewritten text no longer compiled. A method's span includes its body, so a case whose last member is a method passes and hides the bug. Skip whitespace and one `;` past `span.end` before inserting, as `Place::of` does.
