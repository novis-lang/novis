- **A `playwright-core` bump or a fresh `bun install` deletes the downloaded Chromium, and the browser suites then skip and still pass.** The headless shell lives inside `node_modules/playwright-core/.local-browsers`, which the install replaces, and a suite with no browser skips unless `NV_BROWSER` is set. Run the install command in `tools/nv/test/chromium.ts`'s head comment, then run the browser suites with `NV_BROWSER=1`. `until: gone tools/nv/test/chromium.ts:.local-browsers`
