- **A wrap `## commit:` that names a `git mv`'d file's old path fails at that commit, after the ones before it have landed.** `--wrap` validates the sections but runs `git add -- <paths>` only when it reaches each commit, and a path that no longer exists is a fatal pathspec there, so the wrap is not all-or-nothing in that case. Name only the new path. Each commit is limited to its named paths, so the deletion `git mv` staged is left out: commit it by hand after the wrap with `git commit -F <file> -- <old paths>`.
