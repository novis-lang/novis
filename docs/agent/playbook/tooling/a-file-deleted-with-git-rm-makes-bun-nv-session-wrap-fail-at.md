- **A file deleted with `git rm` makes `bun nv session --wrap` fail at its `git add`, after it has already written the handoff.** `applyCommit` in `tools/nv/cmd/session.ts` runs `git add -- <paths>`, and a `git rm`ed path is gone from the index too, so the pathspec errors and nothing is committed. Delete a file the wrap commits with a plain `rm`, or `git restore --staged <path>` before the wrap runs again. [until: gone tools/nv/cmd/session.ts:git", "add]
