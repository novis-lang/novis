- **Delete a file a wrap commit names with Bash `rm`, not `git rm`.** `tools/nv/cmd/session.ts` runs `git add` on every path a `## commit:` names, and `git add` fails on a path that is already gone from both the index and the disk. The failure comes after the handoff is written, so that wrap is not all-or-nothing. If you used `git rm`, run `git reset -- <path>` before you run the wrap again.
