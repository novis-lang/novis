- **A new folder under `benches/` breaks every cargo command until `Cargo.toml` excludes it.** The workspace's `members` globs `benches/*`, so a `.nvs` tree there makes cargo look for a `Cargo.toml` that does not exist and fail before reading any crate. Add the folder to `exclude` in the root `Cargo.toml` in the same slice that creates it, as `benches/scaling` is. [until: gone Cargo.toml:benches/*]
