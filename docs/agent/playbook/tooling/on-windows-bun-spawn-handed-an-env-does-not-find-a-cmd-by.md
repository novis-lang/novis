- **On Windows, `Bun.spawn` handed an `env` does not find a `.cmd` by its bare name, so `npm` fails with `ENOENT ... uv_spawn 'npm'` while `cargo` starts.** Without an `env`, Bun searches `PATHEXT` and a probe from a shell works, which is why every hand reproduction of the driver's red npm checks passed. `tools/nv/lib/proc.ts`'s `resolved` runs `Bun.which` on a bare name before every spawn; a new spawn site goes through `proc.run` or `proc.passthrough`, never `Bun.spawn` directly.
