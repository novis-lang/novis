- **A sweep's nightly CI failures can name a run on an older commit, already fixed at HEAD.** The run's `headSha` can be many commits behind, and the fixes for its jobs (a lockfile bump, a fmt diff, a Miri skip) may already be in `git log`. Before you fix a job, run `gh run view <id> --json headSha` and `git log --oneline <sha>..HEAD -- <the files the job names>`, and fix only what HEAD still fails. `.github/workflows/ci.yml` runs the nightly jobs. `until: gone .github/workflows/ci.yml:miri units`
