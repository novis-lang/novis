- **Bun's `crypto.subtle` does not do X25519, so `tools/webcrypto-vectors.mjs` stops under `bun` at its first ECDH vector.** Bun 1.3.5 throws `NotSupportedError` from `deriveBits({ name: 'X25519' })` where Node returns the shared secret. P-256 ECDH works under both, which is why the failure reads like a problem with the script. Under Bun, `node:crypto`'s `diffieHellman({ privateKey, publicKey })` on `x25519` keys returns the same secret, so the port gets X25519 from there and keeps `crypto.subtle` for everything else.
