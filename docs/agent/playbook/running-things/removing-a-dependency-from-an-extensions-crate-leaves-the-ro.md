- **Removing a dependency from an `extensions/` crate leaves the root `Cargo.lock` stale, and `bun nv gen-attribution` then fails with `cannot update the lock file ... --locked`.** `nvs-ext`'s tests depend on `nvs-image` by path, so any root `cargo test` writes the component's graph into the root lock too. `cargo remove` in the extension prunes only the extension's lock. Run `cargo update --workspace --offline` at the root after removing one, before `gen-attribution`. See `crates/nvs-ext/tests/support/image_arms.rs`. `until: gone crates/nvs-ext/tests/support/image_arms.rs:nvs_image::run`
