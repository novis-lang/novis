- **`bun nv try` runs only a `.nvst` case's `--FILE--`, so a case with `--GET--`, `--COOKIE--` or a `--FILE nvs.toml--` section fails there and passes in the runner.** A `Core\Session::start` throws "there is no request here", and a `[http] csrf_key` the case writes is not read, so the output looks like a bug in the member under test. Run such a case with `target/debug/nvs test <case>.nvst`, which reads every section. See `tools/nv/cmd/try.ts`. `until: gone tools/nv/cmd/try.ts:function sections`
