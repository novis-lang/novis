- **A `bun test` acceptance check with a `tests:` list reads `did not run and pass` while the run says `N pass, 0 fail`.** Bun 1.3 prints only failing tests when `CLAUDECODE` is set, and the loop driver inherits it, so no `(pass)` line carries a test's name. `looper.toml`'s `[checks] env` sets it empty for every check; run a check by hand with `CLAUDECODE= bun test ./path` to see the names. `until: gone looper.toml:CLAUDECODE`
