- **`bun nv site --check` reads `website/dist` as the last build left it, and never builds it, so after a change to a page or a new Core class it reports "not in the built site" and stale example counts.** A `dist` from before another goal's pages names every page that goal added as missing. Those are not real failures. Run `bun nv render --website`, then `bun nv site --build`, then `--check`, before you read the reference leg's list. `referenceProblems` in `tools/nv/cmd/site.ts` reads `DIST`. `until: gone tools/nv/cmd/site.ts:not in the built site`
