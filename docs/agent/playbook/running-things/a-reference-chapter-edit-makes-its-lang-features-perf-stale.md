- **A wording edit to a chapter under `docs/reference/lang/` makes every `lang:` feature of that chapter owe its perf proof again.** A `lang:` feature's implementing file is its reference chapter, so the perf record's `impl_hash` hashes the chapter, and the nightly `proofs` jobs fail with "perf: stale: docs/reference/lang/20-types.md changed since it was last measured" for each section. Run `bun nv proofs --record-perf` after such an edit and commit the records with it. `bun nv proofs --gate` shows what is still owed. See `tools/nv/proofs/roster.ts`. `until: gone tools/nv/proofs/perf.ts:implFile(e)`
