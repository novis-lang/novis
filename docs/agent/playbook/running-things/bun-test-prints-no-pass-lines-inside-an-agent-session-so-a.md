- **`bun test` prints no `(pass)` lines inside an agent session, and the loop's acceptance sweep runs inside one too, so a check whose `tests:` names a bun test is red even when the test passes.** Bun goes quiet when `CLAUDECODE` or `AI_AGENT` is set, so the driver reports "did not run" (`tools/nv/cmd/loop.ts`). A check on a bun test runs `[bun, test, <file>, -t, "<name>"]` with no `tests:` list: `-t` exits 1 when no test matches, so the exit status alone proves the test ran and passed. To read the names yourself, run `env -u CLAUDECODE -u AI_AGENT bun test <file>`. `until: exists bunfig.toml`
