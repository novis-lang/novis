- **A WSL leg's target directory under `/var/tmp` outlives a move of the checkout, and its test binaries keep the old path.** Cargo fingerprints a workspace crate by its path relative to the workspace and does not track `env!("CARGO_MANIFEST_DIR")`, so a `cargo test` after the move rebuilds nothing and `nvs-repo` panics on `/mnt/<old drive>/...: No such file or directory`. `tools/target-checkout.sh` stamps the checkout into the directory and cleans it once when the stamp differs; a new script that keeps a target directory outside the checkout sources it too.
