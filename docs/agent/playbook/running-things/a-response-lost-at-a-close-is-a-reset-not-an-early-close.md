- **A response a client "never got" after the server closed is a reset, not an early close.** A socket dropped with the peer's bytes unread in it sends RST, which discards a response the client has not read yet, and `hyper` leaves an unwanted body unread after one read. A Bun raw-socket probe shows it as `ECONNRESET`; one that only counts responses shows nothing. `close_after_the_response` in `crates/nvs-server/src/serve.rs` sends the FIN first, and its case writes the whole request before reading. `until: gone crates/nvs-server/src/serve.rs:close_after_the_response`
