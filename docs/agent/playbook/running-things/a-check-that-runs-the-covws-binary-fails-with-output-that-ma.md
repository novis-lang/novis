- **A check that runs the `covws` binary fails with output that matches its expected file when you run it by hand.** The instrumented binary merges its counters into `.agent-tmp/select-rec/discard/`, whose `%m` file name can repeat across builds, and a merge into an older build's file appends `LLVM Profile Error` lines to stderr. `buildCovws` empties that pool after each build (`tools/nv/lib/covws.ts`); a binary built some other way still meets the stale file, so delete the pool's `.profraw` files. `until: gone tools/nv/lib/covws.ts:emptyDiscardPool`
