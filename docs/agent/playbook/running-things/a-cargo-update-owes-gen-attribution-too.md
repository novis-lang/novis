- **A `cargo update` that only raises a version still owes `bun nv gen-attribution`.** `THIRD-PARTY-LICENSES.txt` names every crate with its version, so a patch bump for an advisory turns CI's `third-party attribution` job red one push after it turned `supply chain` green. Run `bun nv gen-attribution` right after `cargo update`, and commit both files together. See `tools/nv/cmd/gen-attribution.ts`. `until: gone tools/nv/cmd/gen-attribution.ts:--check`
