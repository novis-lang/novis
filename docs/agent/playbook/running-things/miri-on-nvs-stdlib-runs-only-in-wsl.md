- **Miri on `nvs-stdlib` runs only in WSL.** On Windows, `cargo +nightly miri test -p nvs-stdlib` fails with "cargo uses an argfile to invoke rustc, which is not supported by cargo-miri", and with `--target x86_64-unknown-linux-gnu` a C dependency's build script fails to find `x86_64-linux-gnu-gcc`. Time a Miri test from the WSL copy, as `bun nv deep --only miri-units` runs it, and size a test under `cfg!(miri)` so it ends inside `.config/nextest.toml`'s five minutes. See `crates/nvs-stdlib/src/markdown/tests.rs`.
