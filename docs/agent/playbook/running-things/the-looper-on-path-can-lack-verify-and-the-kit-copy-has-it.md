- **The `looper` on `PATH` can be a build that has no `verify`, and it then prints `unrecognized subcommand 'verify'` and exits `0`.** A background `looper verify` with that output looks like a run that passed. Read its output before you trust its exit status. `bun tools/looper/main.ts verify` is the kit copy in the tree, and `bun nv affected --run` is the end-of-group gate either way. `tools/looper/main.ts` lists the commands. `until: gone tools/looper/main.ts:verify`
