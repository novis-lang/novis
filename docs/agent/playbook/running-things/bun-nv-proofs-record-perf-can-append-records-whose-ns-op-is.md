- **`bun nv proofs --record-perf` can append records whose `ns/op` is `0.0` for most members, and it does not refuse them.** Right after `nv verify`, when the machine is still busy, the loop overhead it subtracts swallows the clock. A bench that declares `complexity linear` then fails in `tools/nv/proofs/perf.ts` with an `Infinityx` ratio, and that failure is the only sign. Read the `ns/op` column before you commit, and if it is mostly `0.0`, discard the appended lines with `git checkout -- docs/perf/members.ndjson` (only while that file has no other uncommitted change) and run it again.
