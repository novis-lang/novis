- **A `docker build` of the Novis bench image is killed as a hang when it is the only thing running.** Its release link prints nothing for over 90 s, and its CPU time is inside Docker's VM, where the watcher cannot see it. `looper.toml`'s `hang_exempt` lets a Bash call through only when the call *starts* with `bun nv bench-compare` or `bun nv bench-proxied`, so a `mkdir … &&` or a `cd … &&` in front of it is watched and killed. Run `bun nv bench-compare --profile <case>` alone, once per case, as its own background command, and read `.agent-tmp/hangs/` before rerunning. `benches/proxied/Dockerfile`
