- **On Windows, a connect to a loopback port where nothing listens takes 2 seconds to fail, so a `localhost` URL for a Docker service costs 2 s on every dial.** Windows retries the SYN after the refusal before it reports it. `localhost` resolves to `::1` first, and Docker publishes the `tests/db/compose.yaml` ports on `127.0.0.1` alone. Write `127.0.0.1` in a test's URL, as `SAMBA_URL` in `crates/nvs-stdlib/tests/ldap.rs` does. `until: gone crates/nvs-stdlib/tests/ldap.rs:SAMBA_URL`
