- **A `--record-perf` over several `Novis\` benches can fail one as growing, when its counts are flat.** The first run after a release build compiles the component and fills the module cache, and that run's allocation count is about 30,000 higher. The batch that pays for it skews the ramp's increments, so `benches/members/novis/Spreadsheet-Reader/rows.nvs` failed with slope 2.01 and then recorded flat alone. Before you read the failure as a leak, check that `nvs run --count` gives the same count twice and grows the same per round. Then record that member again with `--only`. `until: gone tools/nv/proofs/perf.ts:countProgram`
