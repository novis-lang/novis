- **Git Bash rewrites a URL argument that starts with `/` into a Windows path, so `bun nv site --questions --stamp /reference/core/arr/all/` refuses every URL.** MSYS converts any argument that looks like an absolute POSIX path before the program sees it, so `tools/nv/cmd/site.ts` gets `C:/Program Files/Git/reference/...`. Run the command with `MSYS_NO_PATHCONV=1` in the environment, or from PowerShell. `until: gone tools/nv/cmd/site.ts:stampQuestions`
