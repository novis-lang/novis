- **Git Bash rewrites a URL argument that starts with `/` into a Windows path**, so `bun nv site --questions --stamp /reference/core/arr/all/` (`tools/nv/cmd/site.ts`) arrives as `C:/Program Files/Git/reference/...` and every URL is refused. MSYS converts any argument that looks like an absolute POSIX path before the program sees it. Run the command with `MSYS_NO_PATHCONV=1` in the environment, or from PowerShell.
