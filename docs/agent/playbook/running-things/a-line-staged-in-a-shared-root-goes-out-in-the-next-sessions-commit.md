- **A line you stage in a root that another session shares goes out in that session's next commit.** `git apply --cached` put a side loop's 40 perf ledger lines in the index, and the main loop's `git commit` took them under its own message before the side loop committed. Apply a diff to the working tree only and commit it with `git commit -F <msg> -- <path>`, which takes the path's working-tree content and leaves the rest of the index alone.
