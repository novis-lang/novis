- **`bun nv scaling --iterations` (`tools/nv/cmd/scaling.ts`) takes about 30 minutes, and it names the benches that fail before its last summary lines.** If you pipe it through `tail`, you keep the counts and lose which benches failed, and getting the names back costs another full run. Start it with `run_in_background` and no pipe, and read the failing names from its report or from `looper exec log <id>`. `until: gone tools/nv/cmd/scaling.ts:SLOWEST`
