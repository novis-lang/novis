- **A proof build that fails to link with `LNK2019` or `LNK1120` on `anon.*.llvm.*` symbols has a stale `rlib` under `target/proof/`, not a code fault.** The debug build of the same tree is green. `bun nv proofs --overshoot` and `--run` stop at that build, so no program runs. Run `cargo clean --profile proof -p <the crate the errors name>` and run the command again. See `tools/nv/proofs/run.ts`. `until: gone tools/nv/proofs/run.ts:PROOF_BUILD`
