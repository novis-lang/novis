- **`bun nv site --check reference` reads `target/release/nvs.exe` first, so after a change to `nvs meta --json` it reports `core.json` "not current against this binary" and features with "no Reference page".** `bun nv render --website` picks the newest of `target/debug` and `target/release`, and `nv verify` builds neither of those release binaries, so the render and the check read two different documents. Run `cargo build --release`, then `NVS_BIN=target/release/nvs.exe bun nv render --website`, then `bun nv site --build`, before you read the check's list. `binary` in `tools/nv/cmd/site.ts` is the order. `until: gone tools/nv/cmd/site.ts:target/release/${exe}`
