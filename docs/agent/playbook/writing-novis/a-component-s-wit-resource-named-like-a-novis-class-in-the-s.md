- **A component's WIT resource named like a Novis class in the same namespace clashes, because the manifest makes every resource a class there.** `wit/spreadsheet.wit`'s `template` resource would be `Novis\Spreadsheet\Template`, which is the Novis class over it. Name the resource for what it is while in use, and keep the export prefix, as `filling` with its `template-` exports does. Then map the prefix in `crates/nvs-stdlib/tests/ext_world.rs`'s `calls_of`.
