- **A type test on a closed union of shapes fails E0851 when the shape has a `string` field, and `$x is tainted bytes` fails E0813.** The checker treats text taken out of a union by `is` as outside text, and a qualifier is erased at run time, so neither test compiles. Write `$value is tainted {text: string}` and take the field as `tainted string`, and test a `tainted bytes|Core\IO\File` source with `is bytes`, as `extensions/spreadsheet/nvs/Workbook.nvs`'s `csvField` and `extensions/spreadsheet/nvs/Reader.nvs`'s `open` do.
