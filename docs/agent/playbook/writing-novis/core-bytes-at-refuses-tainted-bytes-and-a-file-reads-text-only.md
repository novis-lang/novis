- **`Core\Bytes::at` on `tainted bytes` fails E0401, and `Core\IO\File` has no `bytes` read.** `Core\Taint::assertTrusted` takes a `string` alone, so `tainted bytes` cannot be made plain. To test the first bytes of an upload, turn them into hex text with `Core\Encoding::toHex`, which is contagious, and compare strings. Read a file's raw bytes through an engine call that is lent the file. `extensions/spreadsheet/nvs/Reader.nvs`'s `head` and `workbookStart` do both. A `Novis\` class's `.nvs` source is embedded at build time, so run `cargo build` before you run a program against an edit.
