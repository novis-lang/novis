- **In `extensions/intl/nvs/Collator.nvs`, a parameter default cannot be a shape: `CollateOptions $options = {}` fails with `E0451`.** A default must be a scalar, an enum case or a `const`, so a `Novis\Intl` options parameter cannot be written as `= {}`. Write it `?CollateOptions $options = null` and pass `$options ?? {}` to the `Icu` call, as the image classes do. `until: gone extensions/intl/nvs/Collator.nvs:null`
