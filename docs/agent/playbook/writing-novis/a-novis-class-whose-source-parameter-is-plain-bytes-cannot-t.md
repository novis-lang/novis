- **A `Novis\` class whose source parameter is plain `bytes` cannot take an upload, and every Rust-level test of its component still passes.** An upload is `tainted bytes`, and `nvs check` gives E0401 at the call, which no `crates/nvs-ext` test reaches because those tests call the engine with `Value`s. Before a built-in class's API is called done, run `nvs check` on a probe that passes it `tainted bytes`, as `extensions/spreadsheet/nvs/Reader.nvs`'s `open` needs.
