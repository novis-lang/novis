- **The PDF engine's `Cx::widest` counts the box's own opening, so a box with a `width` measures as that width whatever its content.** A table cell's blocks start with its own `Block::Open`, and `widest` takes an `Open` that does not fill as its full width, so measuring a cell with a `width` gave 124pt for the word `Blog`. To measure a box's content alone, pass `&blocks[1..]`, as `Cx::least_width` in `extensions/pdf/src/layout/flex.rs` does. A cell's nested boxes are also taken from `waiting` by the first layout, so a second layout of the same cell needs `Cx::put_back` first (`extensions/pdf/src/layout/table.rs`). `until: gone extensions/pdf/src/layout/flex.rs:blocks[1..]`
