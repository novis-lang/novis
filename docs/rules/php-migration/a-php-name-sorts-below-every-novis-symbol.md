A PHP-name item appears only where a top-level identifier is legal. A PHP built-in's name is never a
member, so the layer contributes nothing after a receiver or a `::`. Within one response every item of
the layer sorts after every real Novis symbol, `Core` members included: it is a fallback for a name the
developer has not learned yet, and it must never outrank the name they are halfway through typing.

The item's label is the PHP name, because that is what was typed and what the eye is scanning for; the
Novis destination is the item's detail, and the inserted text is whatever
`rule:php-migration/an-item-inserts-only-a-registered-member` permits. The set is returned complete in
one response and the client filters it on later keystrokes — it is a static table of a known size, so
there is nothing to stream and no reason to make the editor ask again.

The whole PHP surface in one position of one language's completion list is a lot of items. Ranking
keeps them out of the way; nothing makes them small, and
`rule:php-migration/completion-php-names-setting` is the developer's own lever.
