# ADR 0276 — An image pipeline starts from encoded bytes, a canvas, raw pixels or set text, and `run` returns the file, the pixels or the size

- **Scope:** where the three `Novis\Image` members that [0120](0120.md) § 3's eight exports did not
  place run — `fromRaw`, `measureText` and `raw` — and where `hashDistance` runs; and the shape of an
  overlay in the `codec` interface's `plan`. The eight exports, the builder and its signatures stay
  0120's.
- **Depends on:** [0120](0120.md) (the builder and the eight exports), [0246](0246.md) (the
  Novis-to-WIT table every `codec` type is written in).
- **Validated by:** `crates/nvs-stdlib/tests/ext_world.rs`: the `codec` interface in `wit/image.wit`
  resolves against the `nvs:ext` world, has exactly the eight exports, and gives every builder member a
  place.

> **In short:** the export set stays 0120's eight. A `source` has four cases: `encoded` (`open`),
> `canvas` (`create`), `pixels` (`fromRaw`) and `text` (`measureText`, a transparent canvas exactly the
> size of the set text). A `plan` carries an `output` — `encoded` (`encode`), `raw` (`raw`: a 16-byte
> size header, then RGBA8 rows) or `size` (the header alone, which is what `measureText` reads) — so
> `run` keeps returning `list<u8>`. `hashDistance` is a Hamming distance over two `bytes` in Novis
> source. An overlay is a row of the plan's flat `overlays` table that a `composite` step names by
> position, and may name only earlier rows.

## Context

0120 § 3 says a `Source` "is either encoded bytes or a blank canvas" and lists eight exports. Writing
the interface placed every § 2 and § 8 member in one of them except four: `Image::fromRaw` starts a
pipeline from pixels the caller already has, `Image::measureText` returns a size and no image, `raw()`
returns pixels with their dimensions, and `Image::hashDistance` compares two hashes. A `composite` step
also takes a whole pipeline, and WIT has no recursive types.

## Decision

### 1. Two new `source` cases, and no new export

`fromRaw` is `source::pixels(raw-image)`, `{width, height, pixels}` as RGBA8 rows. A buffer that is not
exactly `width * height * 4` bytes returns `invalid`, and the pixel cap applies to `width * height` as
it does to a header's declared size. `measureText` is `source::text(text-source)` — the text, the font
bytes, the size, and `max-width` and `align` — run with the `size` output. It lays the text out exactly
as a `text` step does, so the size it returns is the box that step draws.

A ninth export for each was the alternative. It would carry the same input, add a boundary entry point
for a job that is one more pipeline start, and break 0120 § 3's closed count. A source case keeps both
members inside `run`, and a text source can be resized, padded and composited like any other start.

### 2. `run`'s result is chosen by the plan's `output`

`run` returns `list<u8>` for every output. `raw` is a 16-byte header — width, then height, each a
big-endian `u64` — and the RGBA8 rows; `size` is the header alone. The host reads the header into the
`Raw` shape or the size it returns. A `variant` result was the alternative, and it changes § 3's
signature to carry one case two members use. `encode` is the `encoded` output.

### 3. `hashDistance` is Novis source

It is the number of differing bits between two hashes of one kind, which needs no decoder. Calling the
component for it would pay the boundary for a loop over a few bytes.

### 4. An overlay is a table row

A `plan` is `{steps, overlays, output}`. Each overlay row is a `source` and its own `steps`, and a
`composite` step's `overlay` is a position in the table. A row's own `composite` steps name only
earlier rows, so the table is in dependency order and no overlay contains itself; the guest returns
`invalid` for a position that is not earlier. The host flattens a nested Novis pipeline into rows when
it builds the plan.

## Consequences

**Performance:** none on the request path beyond what 0120 already costs: each member stays one
boundary call, and `hashDistance` gets cheaper. `measureText` rasterises the text to size it, which a
metrics-only path would not; the cost is one glyph run, and a later record may add a metrics-only
fast path inside the guest without changing the interface. **Memory:** the `raw` output adds 16 bytes.
**Usability:** no member changes signature. **Simplicity:** one closed export list and one more
`source` case per member, rather than two exports.
