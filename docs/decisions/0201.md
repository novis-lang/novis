# ADR 0201 — a type name brings its `use` line: on paste, from the undeclared-name fix, and from a completion asked inside a call

- **Scope:** how a `use` line reaches a file somebody did not write it in — the paste of copied code,
  the quick fix on an undeclared name, and the completion item accepted for a type — and the two
  completion positions that answered the wrong list. Which types a bare name reaches, and how an
  accepted one is spelled, stay [0193](0193.md)'s and [0194](0194.md)'s.
- **Depends on:** [0193](0193.md), [0099](0099.md), [0040](0040.md).
- **Validated by:** `crates/nvs-hir/src/imports.rs`'s unit tests, `crates/nvs-lsp/tests/imports.rs`,
  `tests/lsp/actions/an-undeclared-class-offers-its-import.lspt`,
  `tests/lsp/completion/an-argument-position-in-a-static-call-offers-the-position-list.lspt`,
  `tests/lsp/completion/the-end-of-an-unresolved-receiver-offers-the-types.lspt`, and the
  `nvs/imports` round trip in `editors/vscode/test/protocol/requests.test.ts`.

> **In short:** code copied out of one file and pasted into another used to arrive without the `use`
> lines that made its type names resolve, and nothing in the editor offered to add them: the name was an
> undeclared-class error with no fix, and completion asked on the name — or inside the call around it —
> answered the members of the class on the left, or nothing. Now the checker's undeclared-name diagnostic
> carries `use Qualified\Name;` for every type the name could have meant, the editor's paste carries the
> imports the copied range resolved and writes the ones the destination lacks, and a cursor at the end of
> a receiver or between a call's parentheses is asked a bare position's question. Where a `use` line goes
> is decided once, in `nvs_hir::imports`, and every one of those readers writes it there.

## Context

### 1. Three readers, one file, no shared answer

[0193](0193.md) made a bare name reach every type and gave the accepted item a `use` line, and put the
logic that finds where the line goes inside the completion module. The checker had no such logic: its
`E0303` said a name was not declared and stopped. A developer who pasted `Core\Debug::dump(Request::headers());`
from a file that imported `Request` into one that did not saw a red squiggle, pressed the fix key and got
nothing, put the cursor after `Request` and asked for completion and got nothing — because the cursor at
a receiver's end was read as the member half of an access whose class did not resolve — and put the
cursor between `dump(` and `)` and got `dump` and `render`, the static members of `Core\Debug`, because
the access node spans its own arguments.

PhpStorm does all three: it carries imports across a paste, offers the import as a fix, and completes
at any cursor. Each is a small feature; what made them one decision is that all three write the same
line into a file, and a file that took one from each would end up with three groups of imports unless
the place was decided once.

### 2. What the paste has to know, and when

At paste time the destination is open and the source may not be. The pasted text's meaning is a fact
about the source as it was at the copy — its namespace, its `use` lines — and a paste minutes later,
into another window, after the source was edited, cannot re-read it. The editor's paste API runs a hook
at copy time in the source document and lets the extension attach data to the clipboard beside the text,
which is exactly the moment and the channel that fact needs.

## Decision

### 3. `nvs_hir::imports` is the one home for where a `use` line goes

`import_site(stmts, src, at)` answers the place for a name written at `at`: after the last `use` the
namespace in force has, failing that after the `namespace Name;` line with a blank line between, failing
that right after the open tag, and `None` for a bracketed namespace with no `use` in it or a file with no
open tag. `candidates(short, symbols, core)` answers which declared or `Core` types a short name could be.
The completion module's own copy of the site logic is deleted and calls this. The open tag is found by
`nvs_syntax::first_open_tag`, the lexer's test over the text, rather than by tokenizing: the hierarchy
collector asks the site at every class declaration so a clause's diagnostic can carry it, and a tokenize
per class would be a compile-time cost for a fix nobody may accept.

### 4. The undeclared-name diagnostic carries the import

`undeclared_name` takes the file's statements and source and the `Core` roster, and attaches one
suggestion per candidate whose replacement is the `use` line at the site. One candidate is a safe fix;
several are unsafe fixes for a person to choose between. A qualified name, a short name an existing `use`
already resolves, and a name with no site get none. The editor's code action provider is unchanged: it
translates suggestions, which is the boundary `rule:ide/a-code-action-ships-only-a-fix-a-diagnostic-already-knows`
draws, and this is the third fix admitted under it. The member resolver and the type checker's
environment carry the statements and the roster to the six sites that raise the diagnostic.

### 5. Two requests carry the imports across a paste

`nvs/imports` takes a document and a range and answers `{symbol, written}` pairs for every type name the
range writes — `::` receivers and `new` names off the syntax walk, annotation names off the written-type
walk `definition` already has, which is generalised from a point to a range — each resolved with
`nvs_hir::resolve_ref` at its own position and kept only where it names something declared or in the
registry. `nvs/importEdits` takes a document, a position and those pairs and answers one text edit: the
`use` lines for every name that would not resolve as written at that position, under a short name nothing
there already answers to, at the site. The extension's `DocumentPasteEditProvider` asks the first on copy
and stores the answer on the clipboard under `application/vnd.code.nvs.imports`, asks the second on paste
and returns the paste with the edit attached under the `text.updateImports.nvs` kind. The editor applies
a provider's edit on its own only for a kind `editor.pasteAs.preferences` names, and that list is empty
by default — a real-editor run showed the plain paste winning — so the extension contributes
`["text.updateImports"]` as that setting's default for Novis documents, which is the one
`configurationDefaults` block it ships. The extension's engine moves to the release that finalised the
paste API.

### 6. Two completion positions are bare positions

A cursor touching the end of an access's receiver is writing the receiver, and a cursor past the member
name with a `(` between the receiver's end and itself is in the arguments or past the call. Both fall
through to the position arms, which offer the type list with its `use` line — so the fix the developer
looked for at `Request|` is the completion item, and `dump(|)` offers what `f(|)` always did.

## Consequences

- A paste from a file that imports a type into one that does not needs no hand-written `use` line; a paste
  whose short name the destination already uses for another type is left as written and gets the
  checker's fix instead.
- `E0303` diagnostics grow suggestions, which `nvs check --json` already prints; `nvs convert` applies no
  suggestion and is unchanged.
- The hierarchy collector computes a site per class declaration — a scan of the statements above it and,
  in a file with no `use` and no namespace, a scan of the text for the open tag.
- The `.lspt` runner learns no request: the two answers have no rendering, and are held by a Rust test
  and the extension's protocol suite.

## Alternatives rejected

- **A quick fix computed by the server** from the diagnostic's span: refused by
  `rule:ide/a-code-action-ships-only-a-fix-a-diagnostic-already-knows`, and it would be the second
  implementation of name resolution `definition`'s module doc refuses.
- **One request at paste time that re-reads the source**: the source may be closed, edited or in another
  window; the clipboard is the only place the copy-time fact survives.
- **Replacing the written name with its qualified spelling** as the fix: determined and cheap, but not
  what a developer asked for, and a file full of `Core\Request` where a `use` line was wanted.
