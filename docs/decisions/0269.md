# ADR 0269 — a file's kind is a plain letter with no colour, because a decoration's colour recolours the file's name

- **Scope:** how the VS Code client draws the kind `nvs/fileKinds` answers. Which files are listed, and
  the request, stay [0268](0268.md)'s.
- **Depends on:** [0268](0268.md).
- **Validated by:** `editors/vscode/test/client/kinds.test.ts`.

> **In short:** the badge stays `C`, `I`, `E` or `T`, and the decoration carries no colour. With a
> colour, every listed file's name turned orange or blue. With none, the editor draws the letter in the
> name's own colour at reduced opacity, and the names keep the colour the theme and source control give
> them.

## Context

### 1. The colour is drawn on the name

[0268](0268.md) gave the decoration the theme's symbol colour for its kind. VS Code draws a
decoration's colour on the file's name as well as on its badge, and there is no way to colour the badge
alone. In a directory of autoloaded files nearly every name is listed, so the whole Explorer became two
or three colours, and the colours no longer marked anything out.

### 2. The badge is text, and nothing else is offered

The stable API takes a badge of one or two characters (`badge?: string`) and draws no shape around it.
A badge drawn as an icon is the proposed `codiconDecoration` API, which an extension published to the
marketplace cannot use, and no API changes how the Explorer shows a file's name.

## Decision

### 1. A plain letter, no colour

The decoration is the letter and the tooltip, with no colour. VS Code draws a badge in the label's own
colour at 75% opacity, so the letter reads as a dimmed mark beside the name, the way a source-control
letter does on a file with no change colour.

## Consequences

`rule:ide/novis-ships-names-not-colours` no longer needs the theme-colour argument [0268](0268.md) § 3
made, because no colour is set. A theme or a user can no longer tell the kinds apart by colour; the
letter and the tooltip are the whole signal.

## Alternatives rejected

### 1. A circled or filled letter

`Ⓒ`, `Ⓘ`, `Ⓔ`, `Ⓣ` and the negative circled letters fit the badge's length and were drawn in the
Explorer's font. The circled ones looked worse than a plain letter, and the filled ones were too small
to tell apart.

### 2. The kind in the file's name

A name such as `Status.enum.nvs` would show the kind with no extension code, and would let an icon
theme give each kind its own icon. It changes how autoload finds a file, which every program's layout
depends on, so it is a language decision and not an editor one.
