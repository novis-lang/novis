# ADR 0225 — a walked goal's test check the permanent suite already runs graduates to one check per crate and per case tree

- **Scope:** what the floor carries in from a walked goal's `cargo-named` and `nvs-suite` checks, and
  what `bun nv chain --check` holds them to. It changes no goal record and nothing a check runs.
- **Depends on:** [0222](0222.md) for the floor as a view over the walked goals.
- **Validated by:** `tools/nv/test/chain.test.ts`, and `bun nv chain --check` over the chain's walked
  goals.

> **In short:** a walked goal's `cargo test -p <crate>` check, alone or narrowed to one target, and its
> `nvs test` over the conformance or differential tree, are checks `nv verify` already runs. The floor
> carries one `cargo test -p <crate>` per crate and one `nvs test tests/<tree>/` per tree in their place.
> A check that asks more than the suite does stays as it is. `bun nv chain --check` fails when a test
> or case a graduated check names is gone.

## Context

The floor grows with every goal the chain walks. When goal `core-process-and-4-more` was live, its
floor held 1070 checks: 527 were `cargo-named` and 112 were `nvs-suite`. Each named a few tests of a
crate `nv verify` tests whole, or a few cases of a tree `nv verify` runs whole. 501 of the 527 were a
plain `cargo test -p <crate>`, and 82 of the 112 were the same `nvs test tests/conformance/` with a
different list of cases. So they ran little that the suite does not run. They added two things: the
driver judged them itself, and a named test that was deleted or renamed turned the floor red.

A check written for an early goal also pins that goal's view of the engine. When the engine moves on,
the check turns red, and a session has to edit the record of a goal it has never seen.

## Options considered

1. Keep every check. The memo keeps the run cheap, but the floor and its stale reds grow with the chain.
2. Drop a walked goal's test checks. The driver would then trust the session's own `nv verify`, and a
   deleted test would leave the floor with nothing noticing.
3. Graduate them: the floor runs the crate or the tree they named, once, and a check over the records
   holds every name they gave to still existing.

## Decision

Option 3. `graduatesTo` in `tools/nv/lib/chain.ts` decides it per check. A `cargo-named` check graduates
when its arguments are `test -p <crate>`, optionally followed by `--lib`, `--bin <name>` or
`--test <name>`, and it has no field but its id, kind, stage, name, arguments and tests. An `nvs-suite`
check graduates when it is `test` over `tests/conformance` or `tests/differential` or a directory in
them, and it has no field but its id, kind, stage, name, arguments and cases. It graduates to
`permanent-suite-<crate>` or `permanent-suite-<tree>`, carried once, with no tests and no cases named.
The goal's own checks never graduate, and neither does a check with `--release`, a feature, a flag after
its target, `--workspace`, `minPassing`, `cwd`, or a tree `nv verify` does not run.

`bun nv chain --check` reads every walked goal's graduated checks. A test name that no tracked Rust
file spells, or a case that is not on disk, is a problem. `bun nv chain --check` is itself a floor check,
so the driver still sees it.

## Consequences

- The floor of goal `core-process-and-4-more` falls from 1070 checks to 481: 18 crate checks and 2 tree
  checks stand for 639.
- The crate checks are the shape the sweep already takes from `nv verify`'s green record, so a session
  that ran `nv verify` pays nothing more. A session that did not pays each changed crate's whole run
  once, as the plain `-p` checks already did.
- Two properties are gone. A graduated `nvs-suite` check no longer fails when a case it named is
  skipped, only when the case is gone. And a test that still exists but stopped being a test, for
  example because its `#[test]` attribute was removed, is no longer noticed.
- The records keep every check, so graduation can be undone by changing `graduatesTo` alone.

## Revisiting

If a floor red is ever traced to a test a graduated check named, and the crate check did not catch it,
the premise is wrong, and that shape stops graduating.
