# ADR 0277 — `Novis\Intl` is eight classes, one per job, whose every member formats a whole list in one locale in one call

- **Scope:** the API of the intl component [0247](0247.md) § 5 builds into every binary: its classes,
  members and options shapes, the exports of `wit/intl.wit`, what a malformed and an unsupported locale
  do, how a `Core\Time` value reaches the guest, and how it relates to `Core\Cldr`. Not in scope:
  message formatting, which § 5 leaves out; how the component is built, embedded and loaded, which is
  0247's; and the value table every export is written in, which is [0246](0246.md)'s.
- **Depends on:** [0247](0247.md) § 5 (the scope), [0051](0051.md) § 3 (the batch shape),
  [0246](0246.md) § 1 (the value table), [0120](0120.md) § 1 (the split between a manifest class and
  Novis source), [0063](0063.md) (no ambient state, one paradigm per operation).
- **Validated by:** `crates/nvs-stdlib/tests/ext_world.rs`: `wit/intl.wit` resolves against the
  `nvs:ext` world in the value table's types alone, and every export but `negotiate` takes a list and
  returns a list.

> **In short:** `Novis\Intl` has one class per job — `Collator`, `NumberFormat`, `PluralRules`,
> `DateFormat`, `RelativeTime`, `ListFormat`, `Segmenter`, `Locale` — written in Novis source over one
> manifest class, `Novis\Intl\Icu`, whose thirteen static methods are the exports of `nvs:intl/icu`.
> Every member takes a list and returns a list in the same order, in one locale, in one crossing; a
> single value is a list of one. `Locale::negotiate`, whose input is one header, is the one member that
> is not a batch. The locale is always an argument. A malformed tag throws `LogicError` naming it; a
> well-formed tag with no data falls back along CLDR's chain, and `Locale::resolve` says which locale
> answered. A `DateTime` reaches the guest as local fields, an offset and a zone id the Novis half
> computed with `Core\Time`, so the guest has no time-zone database. `Core\Cldr` stays, and
> `PluralRules` returns its `PluralCategory`.

## Context

0247 § 5 fixes the scope: collation, numbers (decimal, percent, currency, compact), dates and times over
`Core\Time` values, plural rules, relative time, list formatting, word and sentence segmentation, and
locale negotiation from an `Accept-Language` value. 0051 § 3 fixes the shape: a component crossing costs
a fixed ten-odd nanoseconds plus the copy (`rule:packaging/the-boundary-is-the-cost`), so an API that a
library would offer per item is offered per batch, and collation is a whole-array sort and sort keys,
never a comparator. `rule:core-api/no-ambient-state` forbids a default locale anywhere.

A manifest names exactly one class (`extensions/image/manifest.json`'s `"class"`), and the image
component already settled what that means for an API with more than one job: the manifest class is the
boundary, and the classes a program uses are Novis source in the same `.nvsx` that call it (0120 § 1).

## Decision

### 1. One manifest class, eight job classes in Novis source

The package is `nvs:intl@1.0.0` in `wit/intl.wit`: one interface, `icu`, and one world, `intl`, which
includes `nvs:ext/extension@1.0.0` and exports `icu`. The manifest registers `Novis\Intl\Icu`, whose
static methods are the exports in § 9, one each, under the value table's names. Its help says what
0120 says of `Novis\Image\Codec`: the job classes call it, so a program uses those.

The job classes are Novis source in `extensions/intl/nvs/`. Each member validates nothing the guest
validates, builds the export's record from its options shape, calls one `Icu` method, and maps the
result back. The Novis half does exactly two things the guest cannot: it converts a `Core\Time` value
to local fields (§ 6), and it writes a number as its decimal text (§ 4).

| Class | Member | Signature |
|---|---|---|
| `Collator` | `sort` | `sort(array<string> $strings, string $locale, CollateOptions $options = {}): array<string>` |
| | `sortKeys` | `sortKeys(array<string> $strings, string $locale, CollateOptions $options = {}): array<bytes>` |
| `NumberFormat` | `decimal` | `decimal(array<int\|float\|decimal> $numbers, string $locale, DigitOptions $options = {}): array<string>` |
| | `percent` | `percent(array<int\|float\|decimal> $numbers, string $locale, DigitOptions $options = {}): array<string>` — `0.25` is 25 percent |
| | `currency` | `currency(array<int\|float\|decimal> $amounts, string $currency, string $locale, {display?: CurrencyDisplay} $options = {}): array<string>` — `$currency` is an ISO 4217 code |
| | `compact` | `compact(array<int\|float\|decimal> $numbers, string $locale, {display?: CompactDisplay} $options = {}): array<string>` |
| `PluralRules` | `cardinal` | `cardinal(array<int\|float\|decimal> $numbers, string $locale): array<Core\Cldr\PluralCategory>` |

| `DateFormat` | `dateTimes` | `dateTimes(array<Core\Time\DateTime> $values, string $locale, {length?: Length, seconds?: bool, zone?: ZoneStyle} $options = {}): array<string>` |
| | `dates` | `dates(array<Core\Time\Date> $values, string $locale, {length?: Length} $options = {}): array<string>` |
| | `times` | `times(array<Core\Time\TimeOfDay> $values, string $locale, {seconds?: bool} $options = {}): array<string>` |
| `RelativeTime` | `format` | `format(array<{count: int, unit: TimeUnit}> $items, string $locale, {width?: Width, numeric?: Numeric} $options = {}): array<string>` — a negative count is in the past |
| `ListFormat` | `join` | `join(array<array<string>> $lists, string $locale, {type?: ListType, width?: Width} $options = {}): array<string>` |
| `Segmenter` | `words` | `words(array<string> $strings, string $locale): array<array<{text: string, wordLike: bool}>>` |
| | `sentences` | `sentences(array<string> $strings, string $locale): array<array<string>>` |
| `Locale` | `negotiate` | `negotiate(string $acceptLanguage, array<string> $offered, string $default): string` |
| | `resolve` | `resolve(array<string> $tags, Service $service): array<string>` |

`CollateOptions` is `{strength?: Strength, caseFirst?: CaseFirst, numeric?: bool, ignorePunctuation?:
bool}`, defaulting to `Tertiary`, `Off`, `false` and `false`. `DigitOptions` is `{minFractionDigits?:
uint, maxFractionDigits?: uint, grouping?: bool}`; absent, the locale's own defaults apply, and a
currency's fraction digits are the currency's. The enums are the manifest's, in `Novis\Intl`:
`Strength` (`Primary`, `Secondary`, `Tertiary`, `Quaternary`, `Identical`), `CaseFirst` (`Off`,
`Upper`, `Lower`), `CurrencyDisplay` (`Symbol`, `Narrow`, `Name`, default `Symbol`), `CompactDisplay`
(`Short`, `Long`, default `Short`), `Length` (`Short`, `Medium`, `Long`, default `Medium`),
`ZoneStyle` (`None`, `Offset`, `Location`, `Generic`, default `None`), `TimeUnit` (`Second`, `Minute`,
`Hour`, `Day`, `Week`, `Month`, `Quarter`, `Year`), `Width` (`Wide`, `Short`, `Narrow`, default
`Wide`), `Numeric` (`Always`, `Auto`, default `Always`: `Auto` writes "yesterday" for a count of `-1`
days), `ListType` (`And`, `Or`, `Unit`, default `And`), and `Service` (`Collation`, `Numbers`,
`Plurals`, `Dates`, `RelativeTime`, `Lists`, `Segmentation`).

No member reaches another's job (`rule:core-api/one-paradigm-per-operation`). `sort` and `sortKeys`
are different results, not two spellings: `sort` returns the strings in order, and `sortKeys` returns
bytes a program stores in a column or sorts rows by. The four `NumberFormat` members are four styles
with four options shapes, and `PluralRules`'s two are CLDR's two rule sets, as `Core\Cldr`'s are.

### 2. Every member is a batch, in one locale, in one crossing

Every member but `Locale::negotiate` takes a list and returns a list of the same length in the same
order, and makes exactly one host-to-guest call. A single value is a list of one, at the same one
call. Sorting 10,000 names, formatting a page of prices, and splitting a page of comments into words
each cost one crossing and one copy each way.

One call has one locale. A table whose rows each carry their own locale is one call per locale, which
is the shape a program has anyway when it groups output by reader. A per-item locale would put a
string per item into every crossing, for a case no web page has.

`negotiate` is the exception because its input is one header from one request. A batch of headers is
not a thing a request holds. The test that holds § 2 names it as the only export that takes no list.

### 3. Collation

`sort` returns the input strings in the locale's order; the export returns their positions, so only
`u64`s cross back and the Novis half reorders the list it already has. Equal strings keep their input
order. `sortKeys` returns one key per string. Two keys compare with byte order exactly as the collator
orders their strings, under the same locale and options, and a key is valid only under the pinned
ICU4X version: a stored key is rebuilt when the binary's version of the component changes. `strength`,
`caseFirst`, `numeric` and `ignorePunctuation` are ICU4X's collator options. A collation type the locale
names, such as `de-u-co-phonebk`, comes from the tag (§ 7).

Whether the pinned `icu_collator` writes sort keys itself is not checked here; the session that pins it
writes them from the collator's own key writer or, without one, holds the order equal in its test.

### 4. Numbers and plural categories

A number crosses as its decimal text: an `int` and a `decimal` as their digits, a `float` at the digits
it prints, which is how `Core\Cldr` already reads one. The text is exact, so a `decimal` amount is never
rounded through `f64`, and the export has one numeric type. A `float` that is not finite throws
`RuntimeError` in the Novis half before the call, as `Core\Cldr::pluralCategory` does; a `decimal` with
more digits than ICU4X's decimal type carries returns `runtime`.

`decimal`, `percent` and `compact` are ICU4X's decimal, percent and compact formatters, and `currency`
its currency formatter; as 0247 was written, percent, currency and compact were in `icu_experimental`,
which the component pins with `=` (`rule:packaging/a-dependency-break-is-absorbed-never-forwarded`). A
display case the pinned version lacks is written in the component from the locale's data, never
removed from the enum. A currency code that is not three ASCII letters returns `invalid`.

`cardinal` and `ordinal` return `Core\Cldr\PluralCategory`, the enum `Core\Cldr` already returns. The
export returns its own `plural-category` enum, because an extension's enum is its own
(`nvs_types::ext_lib`), and the Novis half maps each case by name. One category type means a catalog
keyed on `Core\Cldr`'s answer reads `PluralRules`'s with no conversion.

### 5. `Core\Cldr` stays, and the two agree on its roster

`Core\Cldr::pluralCategory` and `ordinalCategory` are Tier 0, answer with no component call, and read
only the language subtag over a closed roster (`crates/nvs-stdlib/src/cldr.rs`). `PluralRules` reads
the whole tag over every locale ICU4X carries. On a bare language tag from `Core\Cldr`'s roster they
return the same category for every number, and a test holds that over a sweep of numbers. They may
differ only where a region has its own rules, such as `pt-PT`, which `Core\Cldr` reads as `pt`. Neither
is deprecated: `Core\Cldr` is the one a template reaches without the sandbox, and `PluralRules` is the
one that knows every locale.

### 6. The host converts time, the guest formats it

`Core\Time` owns the time-zone database, and the guest has none. `dateTimes` converts each `DateTime`
in the Novis half, with `Core\Time`, to the record `local-date-time`: year, month, day, hour, minute,
second, nanoseconds, the UTC offset in seconds, and the IANA zone id. The guest formats the fields, and
names the zone from its id and offset with `ZoneStyle`: `Offset` writes "GMT+2", `Location` writes the
place, and `Generic` the zone's generic name. A zone's specific name ("Central European Summer Time")
needs to know whether the offset is daylight time, and is left for a later record. Which `Core\Time`
accessors the Novis half reads is the implementing session's; it is not checked here that one returns
the offset directly.

`dates` and `times` cross as `nvs:ext/types`' own `date` and `time-of-day` records, which already are
local fields. A `DateTime` does not cross as the `date-time` record, because that record is an instant
and a zone name, and turning it into fields is the time-zone database's job. An `Instant` is placed in
its zone with `Core\Time` first; a member taking an `Instant` and a `Zone` would be a second way to
write `dateTimes`.

The calendar is the locale's: a tag's `-u-ca-` keyword selects one, and the fields cross as ISO
(Gregorian) fields that the guest converts.

### 7. The locale is an argument, and what a bad one does

Every member takes the locale as an argument; there is no default locale, no setting that holds one, and
no `[intl]` configuration block. A locale is a BCP 47 tag, and the guest parses it.

- **A malformed tag** returns `invalid`, which throws `LogicError` naming the tag, cut to its first 64
  characters. The locale is the program's own data, so a bad one is a bug.
- **A well-formed tag with no data** falls back along CLDR's chain (`de-AT-x-shop` to `de-AT` to `de`,
  and at last to the root locale) and formats. It never throws: a tag the program got from a user or a
  header is well-formed and still unknown far more often than it is wrong.
- **`Locale::resolve`** returns, for each tag, the locale whose data answers for a `Service`: `de-CH`
  for `de-CH` where Swiss data exists, `de` where only German does, and `und` where only the root
  does. Coverage differs between services, so the service is an argument. This is how a program learns
  which locale answered.
- **A `-u-` keyword an option also names** is an error, not a second way to write the option:
  `-u-ks-`, `-u-kf-` and `-u-kn-` beside `strength`, `caseFirst` or `numeric` return `invalid`. A
  keyword no option names — `co`, `nu`, `ca`, `hc` — is read from the tag, so a user's preference
  travels with their locale.

### 8. Segmentation and negotiation

`words` returns every segment of each string, with `wordLike` true for a word and false for spaces and
punctuation, so the segments joined give the string back. `sentences` returns each sentence with its
trailing space. The locale selects the dictionary or model for languages written without spaces, as far
as `compiled_data` carries one. Grapheme segmentation is `Core\Str`'s and is not repeated (0051 § 3).

`negotiate` parses the header by its quality values, reads at most its first 32 ranges, matches each
against `$offered` with CLDR's fallback (`de-AT` reaches `de`), and returns the offered tag, spelt as
`$offered` spells it, of the best match. An empty or malformed header, or one that matches nothing,
returns `$default`. It never throws for the header, because the header is request data the program
does not control; a malformed tag in `$offered` or `$default` is the program's own and throws
`LogicError`. The 32-range bound keeps a hostile header's cost fixed, and no browser sends a tenth of it.

### 9. The exports of `nvs:intl/icu`

Every export returns `result<T, error>` with `nvs:ext/types`' `error`, so `invalid`, `parse` and
`runtime` throw `LogicError`, `ParseError` and `RuntimeError` (`rule:packaging/a-guest-crash-throws`).

| Export | Takes | Returns | Members |
|---|---|---|---|
| `collate-order` | `list<string>`, locale, `collate-options` | `list<u64>` | `Collator::sort` |
| `sort-keys` | `list<string>`, locale, `collate-options` | `list<list<u8>>` | `Collator::sortKeys` |
| `format-numbers` | `list<string>`, locale, `number-options` | `list<string>` | the four `NumberFormat` members, by `style` |
| `plural-categories` | `list<string>`, locale, `plural-kind` | `list<plural-category>` | `PluralRules::cardinal`, `::ordinal` |
| `format-date-times` | `list<local-date-time>`, locale, `date-time-options` | `list<string>` | `DateFormat::dateTimes` |
| `format-dates` | `list<date>`, locale, `length` | `list<string>` | `DateFormat::dates` |
| `format-times` | `list<time-of-day>`, locale, `time-options` | `list<string>` | `DateFormat::times` |
| `format-relative` | `list<relative-item>`, locale, `relative-options` | `list<string>` | `RelativeTime::format` |
| `format-lists` | `list<list<string>>`, locale, `list-options` | `list<string>` | `ListFormat::join` |
| `word-segments` | `list<string>`, locale | `list<list<word>>` | `Segmenter::words` |
| `sentence-segments` | `list<string>`, locale | `list<list<string>>` | `Segmenter::sentences` |
| `resolve-locales` | `list<string>`, `service` | `list<string>` | `Locale::resolve` |
| `negotiate` | the header, `list<string>`, default | `string` | `Locale::negotiate` |

`wit/intl.wit` is the authority for every record and enum; this table names them.

### 10. The data, and what it costs

The component carries ICU4X's `compiled_data`, the crates 0247 § 5's list needs: `icu_collator`,
`icu_decimal`, `icu_plurals`, `icu_datetime`, `icu_list`, `icu_segmenter`, `icu_locale`, and
`icu_experimental` for what ICU4X has not stabilised. "Every CLDR locale" is the locale set
`compiled_data` bakes in. Whether that is CLDR's whole set or ICU4X's default coverage level is not
checked here; the session that pins the crates states which in the component's module doc, and the
binary's growth is measured and stated there too.

## Consequences

**Performance:** one crossing per batch, so a sort of 10,000 names or a page of prices is one call, and a
single value costs the same one call. `sort` sends the strings once and receives only positions back.
**Memory:** nothing until a process first calls the component; then the compiled module, shared by every
core, and each calling request's instance under that request's cap. A batch costs its input and output
copied once each way, and a large batch is bounded by the request's memory cap like any other value. The
CLDR data is in the binary, measured when the component lands. **Usability:** locale-correct sorting,
numbers, dates, lists, segmentation and negotiation on every install with no configuration; a single value
is written as a list of one, which is one pair of brackets. **Simplicity:** eight classes, one per job,
seventeen members and thirteen exports; one more component through the build step the image component
already uses.

## Alternatives rejected

- **A comparator, or a per-value member beside each batch member.** The comparator is the 130,000
  crossings 0051 § 3 rejects. A per-value twin would be the second way to reach every operation that
  `rule:core-api/one-paradigm-per-operation` refuses, and saves only the brackets.
- **A default locale** — a setting, a per-request value, or the `Accept-Language` of the current
  request read implicitly. Each is ambient state (`rule:core-api/no-ambient-state`).
- **Numbers as a `variant` of `s64`, `f64` and digits.** It adds three cases to every numeric export to
  carry what one string already carries exactly.
- **A second time-zone database in the guest**, so a `DateTime` crosses as its instant. It doubles data
  `Core\Time` already carries, and two databases can disagree about the same instant.
- **`RelativeTime` from a `Duration`.** A month and a year are not a fixed number of nanoseconds, so the
  unit would be a guess. The program chooses the unit and the count.
- **Throwing for an unknown but well-formed locale.** A user's locale is unknown far more often than it
  is wrong, and a page that throws for `gsw` is worse than one in German.

## Revisiting

When ICU4X stabilises MessageFormat 2, message formatting is a new record adding a class, as 0247 § 5
says. When the measured data size is too large, the answer is a slimmer locale set, never an optional
component (0247).

## Verification

`crates/nvs-stdlib/tests/ext_world.rs` holds § 9: `wit/intl.wit` resolves against the world, every
export returns the `error`, every type is one the value table gives, and every export but `negotiate`
takes a list and returns a list. The behaviour of each class is held by the intl component's tests in
`crates/nvs-ext/tests/intl.rs` and `tests/conformance/novis/`, and each class's proofs by a
`bun nv proofs --verify --group` check in the goal that builds it.
