# Decision records

Each `NNNN.md` here is a frozen record: the reasoning behind a decision, never edited to track a later
one. A rule's fragment under [docs/rules/](../rules/) is the rule, and it reaches its record through
its `because`. [docs/ground-rules.md](../ground-rules.md) lists every rule, and
[docs/decisions.md](../decisions.md) every decision in plain language.
