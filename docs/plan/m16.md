# M16 — `nvs/web`, `nvs new`, and the framework (~12 weeks)

**Backlog 5.** The server and `Core` it builds on are on disk; what keeps it behind M15 is that
`nvs new`'s scaffold resolves `nvs/web` through the package client, and its `package.lock` is part of
this milestone's own acceptance.

`rule:programs/first-party-framework` is the split and the roster. The privileged half is built, in
`Core`; **this milestone is the package** — `Web\Controller` and the middleware pipeline
over `rule:routing/routes-are-compiled-not-registered`'s table, `Web\Response`, `Web\Auth`, `Web\Validation`,
`Web\Mail`, `Web\I18n`, `Web\Storage`, `Web\Pagination`, `Web\Job`, `Web\Api` — plus `nvs new`. Wiring is
constructor injection resolved through
`rule:programs/implementing`'s enumeration, so a missing binding
is a compile error and there is no runtime container. There is no ORM and no template engine, for the
reasons that rule gives. The dispatcher that calls a `Web\Controller` route method binds each `#[Query]`
parameter from the query string, and a value that does not convert is a `400`
(`rule:routing/a-bad-query-value-is-a-400`).

**`Web\Migration` is blocked, deliberately.** `rule:programs/no-migration-runner` records
the open gap — ordering, transactional DDL, fleet locking, reversibility, safety against a live
multi-tenant database — and nothing in the package may ship a migration runner until a rule closes it. That
rule is the prerequisite for this milestone finishing, not a follow-up to it.

**Verify:** `nvs new` compiles, serves its routes, authenticates a session, reads a row and passes its
`#[Test]`, on all three platforms, as a first-class CI job. Its `package.lock` names `nvs/web` and nothing
else. Deleting the scaffold's validation call makes it fail to compile — the assertion that the qualifier
demonstration is real. And a fixture in which `nvs/web` tries to return an unqualified `string` derived from
a `tainted` one fails to compile, proving the framework is subject to
`rule:security/launderers-are-sink-named` like any other package.
