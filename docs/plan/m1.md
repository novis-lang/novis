# M1 — Front end (~3 weeks)

**Carried by goal `surface`.** Everything here landed with M1 itself except item 5 below, the pipeline
operator, which [goal `surface`](../agent/goals/15-surface.md) takes; the milestone is not `done` until it
does.

Lexer with dual mode (`<?nvs`, `<?php`, `<?=`), inline HTML, heredoc/nowdoc, string interpolation, all
PHP 8.5 tokens. Recursive-descent parser covering the pragmatic-superset grammar: classes, interfaces,
enums (cases and an optional backing type only — no methods, no `implements`, see
`rule:enums/closed-integer-type`), methods (a `function` declaration is only ever a class
member, static or instance — see `rule:classes/no-free-functions-or-constants`),
attributes, `match`, `fn` closures — with or without a block body, and with an optional self-name for
recursion, but no anonymous `function(...) {...}` literal and no `use` clause at all
(`rule:types/closure-literal`) — generators, named arguments, spread, nullsafe,
`readonly`, promoted constructor parameters, first-class callable syntax, property hooks (their pipeline
relative to the new `PropertyObserver` interface is `rule:classes/property-observer`), asymmetric
visibility. Rejects, with a diagnostic naming the replacement, every construct an earlier ADR closes:
`eval`/`$$var`/`goto`/`global`/`extract`/`settype`/function-scope `static`/`static fn`
(`rule:statements/static-is-a-member-modifier`), anonymous `function(...) {...}`/`function(...) use (...) {...}`
and any `use` capture clause (`rule:types/closure-literal`), enum
methods/`implements`/`string` backing
(`rule:enums/closed-integer-type`), a `function` or `const` outside a class body and a
`namespace` or class named `Core` (`rule:classes/no-free-functions-or-constants`),
every superglobal spelling (`rule:statements/no-host-populated-variables`), and `use … as …`
(`rule:statements/nothing-gets-a-second-name`). Error recovery good enough for the LSP.

**M1 is re-opened twice more, once for a check that is now built and once for a spelling that is not.**

`rule:security/bidi-predicate`'s predicate over every string
literal, comment and inline-HTML run is **built**: `nvs_render::bidi` is the one implementation of the
rule, the lexer reports `E0008` with no suppression, and each line of a multi-line token is its own span so
a heredoc cannot hide a scope across them. The predicate lives in `nvs-render` rather than beside the lexer
because its other callers import it rather than restate it and `rule:errors/diagnostic-record` makes that crate the leaf both
the runtime and the front end depend on; `nvs-render`'s § *Where this sits* owns the move.
Identifiers need nothing: they are already ASCII-only, which is what closes the homoglyph half of Trojan
Source structurally.

`rule:expressions/one-equality-operator` is **not** built and is
this milestone's open item: the lexer still produces `===` and `!==`, which that ADR deletes. Removing them
takes `BinaryOp::Identical`/`NotIdentical` out of the AST with them and rewrites every fixture and `.nvst`
case that writes the rejected spelling. The rest of that ADR is M2's and M3/M4's, below.

Plus the type grammar of `rule:types/declaration`, which is a parser problem before it
is a checker one: nested `array<T>`, DNF unions and intersections, `uint`, the conversion operator
including its nullable form `as ?T` (`rule:expressions/nullable-conversion`), and the
declaration slots PHP has no syntax for — typed locals, `foreach` bindings and destructuring targets. Also
in the grammar, each *parsed* here and *enforced* in M2: the `tainted` and `secret` qualifiers on
`string`/`bytes`, composable only as `secret tainted T`
(`rule:security/tainted-qualifier`,
`rule:security/secret-qualifier`); `type Name = TypeExpr;`
(`rule:statements/nothing-gets-a-second-name`); the anonymous object literal `{a: 1}` and the inline shape type
`{name: T}`, whose two collisions with a block body and a block statement are resolved by requiring
parentheses, diagnosed by name at both sites (`rule:types/object-top`); and
`implements Interface by $field` plus a body on an interface method, replacing the `trait`/`use
TraitName`/`insteadof` grammar that is now a parse-time `E_TRAIT_NOT_SUPPORTED`
(`rule:classes/no-traits`).

**Still owed — five ADRs accepted after this milestone was reported done add grammar it owns.** Items 1-4
are parser-and-lexer work that M2's checker slice is already scheduled against, so each blocks its ADR
rather than being optional; **item 5 is the one that blocks nothing**, and its own entry says what follows
from that. Items 1-4 are built; item 5 is not:

1. **`decimal`** (`rule:types/decimal`) — **built**, and its M2 checker rows with
   it: the reserved keyword, the type atom, § 2's untyped-until-placed literal (including `as T` as a
   placing position), § 1's mantissa and scale bounds, and § 3's arithmetic table. A trailing `m` is a
   stray identifier the parser refuses, not a suffix. The runtime half is built too: `nvs_ir::ty::Ty::Decimal`
   is the representation and `nvs_runtime::decimal` the value behind it.
2. **Literal and enum-case type atoms** (`rule:types/literal-types`) —
   **built**, grammar only: a `StringLiteral`/`IntLiteral` atom, unions of them, `?"a"` sugar, and a
   class-constant or enum-case reference in type position, which needed no production beyond the
   `ClassName`/`EnumName` ambiguity `rule:statements/an-enum-name-is-a-type-everywhere` already established. That ADR's M2 row — § 4's
   assignability and conversion table — is **not** built, and the checker refuses all three atoms by name
   until it is; that ADR's *Verification* section owns why, and names the one step the table's own wording
   understates.
3. **`autoload`** (`rule:programs/no-runtime-autoload`) — **built**,
   both file-scope declaration forms whose grammar
   [`docs/spec/00-overview.md`](../spec/00-overview.md) § 2 fixes: the explicit multi-root
   `from 'a', 'b'` and the contextual `discover '<glob>'`. M2's name-to-file fixpoint resolves over
   `crates/nvs-hir/src/autoload.rs`'s map, and the conformance tree holds the cases.
4. **The duration literal** (`rule:types/duration-literal`) — **built**, and its M2 and M4S
   halves with it: one `DurationLiteral` token over `( DEC_INT unit )+`, typed `Core\Time\Duration` with
   nothing placing it, folded to a nanosecond count and lowered to the one member that also serves a
   computed `Duration::nanoseconds($n)`. The grammar is `crates/nvs-syntax/src/duration.rs`, shared with
   `Duration::parse` and with M6's `nvs.toml` exactly as § 5 requires. It met item 1 at the lexer, and the
   ADR decided the boundary: `1.5s` is that grammar's own fractional refusal, so `19.99m` is refused there
   too rather than lexing as two tokens — a suffix *outside* the unit alphabet, like `19.99x`, still does.
5. **The pipeline operator** (`rule:expressions/pipeline-substitution`)
   — the `|>` token, the `$_` hole, § 2's precedence level, and `E0129`/`E0130`/`E0131`. Confined to
   `nvs-syntax`: the operator substitutes in the parser, so what reaches `nvs-hir` and everything after it
   is the `ExprKind` the nested spelling already produces. **This is the one item here that blocks
   nothing** — no ADR waits on it, no scheduled M2 slice needs it, and it invalidates no fixture, because
   every nested call site stays correct whether or not it is ever rewritten. That is why it is **scheduled
   after the current loop goal rather than into it**: Stage 0's admission test is that a fixture written
   while an item is open is written against a rule about to change, and nothing here changes a rule. The
   corpus the loop is writing now is also the evidence that decides that ADR's deferred `?|>`. It is
   [goal `surface`](../agent/goals/15-surface.md) that finally writes it, ahead of the grammar goals `lsp-server` and `editor`
   colour, so a surface about to change is not written against twice.
6. **The PHP 8.6 refusals** (`rule:php-migration/a-deprecation-is-a-refusal`)
   — `let` and `is` join `crates/nvs-syntax/src/token.rs`'s reserved set, and three front-end checks land
   with their codes and `--EXPECTF-ERROR--` cases: a `return` (or an escaping `break`/`continue`) inside
   `finally` (§ 1), `return $value;` in a constructor (§ 2), and a default on a `readonly` property (§ 4).
   Confined to the front end like item 5, and **blocking nothing** — every refusal names code no fixture
   writes — so it is scheduled after the current loop goal on the same argument.

**Verify:** `nvs ast file.nvs` dumps the AST; `insta` snapshot tests; `cargo fuzz` on the lexer and parser
finds no panic in a 5 minute run. A snapshot pins the one grammar wrinkle in
`rule:types/declaration`: `as` in a `foreach` header belongs to `foreach`, so a conversion of the subject needs
parentheses. The six additions above each carry their own ADR's M1 verification line.
