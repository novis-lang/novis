== DECISIONS WITH NO ADR (titles only)
-- source: docs/adr/README.md section 'Decisions taken at project start'

- Rust as the implementation language.
- Cranelift JIT as the only execution tier, no interpreter.
- `exit` is a fourth ABI status, not a `FATAL` carrying a code.
- SIMD is a dependency's job, and the JIT emits scalar code.
- Thread-per-core, shared-nothing runtime.
- Stackful coroutines for suspension.
- Isolated workers for CPU parallelism.
- Strict shared-nothing requests.
- Safepoints emitted from the first backend commit.
- Server-level configuration, not per-project.
- Pure-Rust dependencies by default.
- Domain logic is an existing first-class Rust crate; compiler passes and scheduler primitives are ours.
- Checked-return call sites go through one code path.
- `unsafe` is confined to named crates, each declaring its own policy.
- `continue` inside a `switch` continues the enclosing loop.
- A written level counts the way PHP counts, and `continue` then walks outward.
- A ternary's or a `match`'s branches join at the union's erasure, and widen at the binding.
- A method call needs a class label, so an erased receiver is refused rather than dispatched.
- property
- once per process
- non-`public`
- An `inout` parameter belongs only to a frame the call site outlives.
- generator
- Architecture assumptions are tested, not remembered.
- A `static` property's storage is the request's, not the process's.
- A `class`, `interface` or `enum` is declared at file scope, or not at all.
- A `try` has at least one `catch` or a `finally`, and a `catch` clause names exactly one class.
- A class or interface constant writes its type.
- `namespace X;` is the only namespace statement — once per file, before any declaration.
- One `use` names one import; PHP's group form is refused.
