The Novis extension for VS Code colours `.nvs` files. It also shows errors while you type and
completes the names of variables and methods. When the mouse pointer is over a method, it shows the
documentation of that method. It gets all of
this from `nvs lsp`, the language server that is part of the `nvs` program.

## Install the extension

The extension is not in the VS Code Marketplace. Each release has it as a file, and you install that
file.

<Steps>

1. Download <a href={vsix.url}><code>{vsix.file}</code></a> from the current release.

2. Install it. In VS Code, open the command palette and run **Extensions: Install from VSIX...**.
   Then choose the file. You can also install it from a terminal:

   <Code lang="sh" code={`code --install-extension ${vsix.file}`} />

3. Open a `.nvs` file. The status bar shows the version of `nvs` that the extension uses.

</Steps>

### Build the extension from source

You need [Node.js](https://nodejs.org/) and the Novis source code from [Install Novis](/install/).

<Steps>

1. Build the extension:

   ```sh
   cd editors/vscode
   npm ci
   npm run package
   ```

   This writes `nvs.vsix` into `editors/vscode`.

2. Install it:

   ```sh
   code --install-extension nvs.vsix
   ```

   You can also run **Extensions: Install from VSIX...** in VS Code.

</Steps>

## How the extension finds nvs

The extension does not include `nvs`. It looks in three places, in this order:

1. the path in the setting `nvs.path`;
2. `nvs` on your `PATH`;
3. a copy that the command **Novis: Download nvs** installed.

The extension and `nvs` must have the same version number before the second dot. For example,
extension `0.4.2` works with `nvs` `0.4.0`, and does not work with `nvs` `0.5.0`.

## Settings you may change

| Setting | Default | What it does |
|---|---|---|
| `nvs.path` | `""` | The full path to the `nvs` program. Empty means: find `nvs` on the `PATH`. |
| `nvs.lsp.enable` | `true` | Starts the language server. With `false`, you get colours and nothing else. |
| `nvs.check.scope` | `"workspace"` | Which files are checked: `workspace` for every file in the folder, or `open` for the open files. |
| `nvs.secrets.redact` | `true` | Hides values of a `secret` type, such as a password. |
| `nvs.taint.mark` | `"off"` | Shows a sign next to `tainted` values, which come from outside the program. Use `declaration` or `sink` to turn it on. |
| `nvs.codeLens.enable` | `true` | Shows above each declaration how often it is used. |

A change to `nvs.path` or `nvs.lsp.enable` restarts the server. After a change to another setting,
run **Novis: Restart Language Server**.

## Tainted and secret variables

The language server tells VS Code which variables are `tainted` and which are `secret`. A tainted
value comes from outside the program, such as a request. This works at every place where you use the
variable.

Your color theme decides how these variables look. In the themes that come with VS Code, a tainted
variable is underlined and a secret variable is in italic. Some other themes show no difference.

To choose the style yourself, add this to your `settings.json`:

```json
"editor.semanticTokenColorCustomizations": {
  "enabled": true,
  "rules": {
    "*.tainted": { "underline": true },
    "*.secret": { "italic": true }
  }
}
```

`"enabled": true` is needed for a theme that does not use the language server's colors.

## Commands

Open the command palette and type **Novis**. These are the commands you use most:

| Command | What it does |
|---|---|
| **Novis: Run File** | Checks, compiles and runs the open file. |
| **Novis: Run Tests** | Runs the `#[Test]` methods in the open file. |
| **Novis: Restart Language Server** | Stops the server and starts it again. |
| **Novis: Reveal Secret** | Shows the hidden value under the cursor. |
| **Novis: Hide Secrets** | Hides every value you revealed again. |
| **Novis: Download nvs** | Downloads the newest `nvs` that works with this extension. |

**Novis: Download nvs** checks the download against the release's checksum file before it uses
it. Nothing is downloaded unless you run this command.
