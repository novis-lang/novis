Novis is a programming language for two kinds of program. The first kind is a web server that
answers requests. The second kind is a program you start from the command line, such as a script,
a report or a scheduled job. The syntax is close to PHP, so most PHP programmers can read Novis
at once. [Start here](/syntax/start-here/) shows the differences.

## Secure first, then fast

Novis has one goal for both kinds of program: run them securely and fast. Security comes first.
When a design is faster but less safe, Novis takes the safer design.

A web server reads input from people it does not know. So Novis checks the most common mistakes
before your program runs:

- Text from a request is tainted. You must check or escape it before it reaches a database query,
  a shell command or an HTML page. Read more in [Tainted input](/in-depth/concepts/tainted-input/).
- Each request runs on its own. A request that crashes or loops forever stops only itself. Read
  more in [One request cannot hurt another](/in-depth/concepts/isolation/).
- Each request has limits for memory and time, which you set in `nvs.toml`. Read more in
  [Memory and CPU limits](/in-depth/concepts/limits/).

## Fast without extra work

Novis compiles your code to machine code before it runs. You do not need a build step and you do
not need to tune anything. Read more in [Compiled, never interpreted](/in-depth/concepts/compiled/).

## Everything in one binary

`nvs` is one program. It runs your code, serves web requests, runs your tests and formats your
files. The standard library comes with it. It has classes for JSON, databases, HTTP, passwords,
dates and much more. Most programs need no package from outside.
