This page describes the direction of Novis as a whole. Each section names one thing that Novis will
never become, and the reason. These points are true for every version of Novis.

## A different language later

Novis is a language for web applications and command-line scripts. It will stay that language. A
new version adds features for these two kinds of program. It does not turn Novis into a language
for something else, such as games or phone apps.

The priorities also stay the same, in the same order. [How we decide](/in-depth/how-we-decide/)
lists them.

## A standard library for every possible job

Novis does not try to include everything that a web application could ever need. It looks at the
jobs that almost every web application has, and at the security mistakes that are most common in
them. Examples are database queries, HTML output, forms, file uploads and passwords.

For each of these jobs, Novis gives one way that is simple, secure and the same in every program. A
rare job belongs in your own code. This keeps the standard library easy to learn and easy to keep
secure.

## Software that nobody checked

Novis is written with coding agents. Code that nobody planned and nobody checked is often called
"AI slop". Novis will never be that kind of software.

A feature is finished only when it has tests, examples, a benchmark and an attack. When a mistake
gets past the checks, we add the missing test. So the proof that Novis works gets stronger with each
version. [How Novis is written](/in-depth/how-novis-is-written/) and
[How Novis is tested](/in-depth/how-novis-is-tested/) show every check.

## The fastest language in every benchmark

Speed is important for Novis, but it is the second priority. Security comes first. When a design is
faster but less safe, Novis takes the safer design. Within that limit, Novis is as fast as possible.

Novis also uses memory to be safe and fast. Each request has its own memory, and compiled code stays
in memory. So a Novis server can use more memory than a server written in another language. Every
request still has a memory limit that you set.
<a href={githubFile('docs/rules/programs/memory-priority.md')}>Read the full reasoning.</a>

## A language that only an AI can use

Novis is made for people. A developer can learn it without an AI tool. Every feature has a page on
this website, with examples. `nvs` prints help for every command and flag. An error message says
what is wrong and what you can do about it.

You can use an AI tool to write Novis code. Every design choice still makes sure that a person can
read that code and understand it.
