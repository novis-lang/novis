## Version 0.1 (preview — not released)

### Highlights

- **The pure Core** — `Core\Str`, `Core\Arr`, `Core\Math`, `Core\Regex`, `Core\Json`,
  `Core\Path` and friends: implemented, tested and documented in the
  [Core reference](/reference/core/).
- **Checked-status error propagation** — a `throw` costs no more than a `return`.
- **Structured concurrency** — `Core\Task::all` and `Core\Task::map` with cancellation
  and deadlines.

### Breaking changes

- None — there is no previous release to break.
