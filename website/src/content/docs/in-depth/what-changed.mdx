This page lists the changes in each release of Novis, newest first. Each release has three parts:
the highlights, the new features and the changes that can break your code.

:::note
Novis has no numbered release yet. The section below shows the form that release notes will have.
It does not describe a real release.
:::

## Version 0.1 (not released)

### Highlights

- The standard library: `Core\Str`, `Core\Arr`, `Core\Json`, `Core\Db` and many more classes. The
  [Core reference](/reference/core/) lists all of them.
- `nvs serve`: a web server that runs each request on its own, with limits that you set.
- `nvs test`: tests are written in Novis, next to the code they test.

### Changes that can break your code

None. There is no earlier release.

The [Roadmap](/in-depth/roadmap/) says what comes after this release.
