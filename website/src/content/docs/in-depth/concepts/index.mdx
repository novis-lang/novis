Each page explains one idea: what it is, why Novis has it and what it means for your code.

- [One request cannot change another](/in-depth/concepts/isolation/): each request runs on its own.
- [Tainted input](/in-depth/concepts/tainted-input/): the compiler tracks text from outside.
- [How property name types work](/in-depth/concepts/checked-property-names/): property names in a
  string are checked against your classes.
- [Memory and CPU limits](/in-depth/concepts/limits/): every request has limits that you set.
- [Compiled, never interpreted](/in-depth/concepts/compiled/): your code runs as machine code.
- [Strings are UTF-8](/in-depth/concepts/utf8-strings/): a string is always valid text.
