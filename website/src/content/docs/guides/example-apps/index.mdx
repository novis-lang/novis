An example app is a complete project. It has its configuration, its classes, its pages and its
tests. You can run it on your computer in a few minutes. You can also copy it and change it into
your own app.

Each app is in the folder `apps/` of the Novis repository. Each app is tested with every change to
Novis, so it always runs with the current version.

- [Notes](/guides/example-apps/notes/) saves notes in SQLite. It shows them as HTML pages and has a
  small JSON API. It also checks the form and has tests.

Before you start, [install Novis](/install/). Then read the [Tour](/guides/tour/) if you have not
written Novis before.
