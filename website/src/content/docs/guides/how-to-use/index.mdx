These pages show how the parts of a Novis application work together. Each page ends with a short
list of things to do and things to avoid.

- [Project layout](/guides/how-to-use/project-layout/) shows where the entry file, your classes,
  the tests and `nvs.toml` go.
- [Configuration](/guides/how-to-use/configuration/) explains `nvs.toml`: what it controls, and
  how to check it.
- [Handling requests](/guides/how-to-use/requests/) shows how a program finds its route and reads
  the request.
- [Errors](/guides/how-to-use/errors/) shows how to throw your own errors and handle them in one
  place.
- [Tainted input](/guides/how-to-use/tainted-input/) explains how Novis tracks values from outside
  the program.
- [Limits](/guides/how-to-use/limits/) shows how to limit the memory and time of each request.

Read the [Tour](/guides/tour/) first if you have not written a Novis program yet.
