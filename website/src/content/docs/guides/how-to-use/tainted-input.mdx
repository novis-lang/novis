A value that comes from outside the program is `tainted`. This includes the address, a form field,
a header, a cookie and a JSON body. The type of such a value is `tainted string`, not `string`.

- `Core\Request::query` and `Core\Request::post` return a `?tainted string`.
- `Core\Request::queryArray` and `Core\Request::postArray` return an `array<tainted string>`.
- `Core\Request::json` returns `mixed`. Text you convert from a `mixed` value with `as string` is
  a `tainted string`.
- In a `foreach` over such an array, the key is a `tainted string` too.

The compiler checks every place where your code uses a tainted value. You cannot pass it where a plain `string` is
needed, so it cannot reach SQL, a file name or HTML without a check.

## The safe ways to use it

<Snippet src="guides/how-to-use/tainted-input/tainted-input.nvs" />

The output above is for the address `/search?q=<b>tea</b>&page=2`. The program uses two of the
safe ways:

- `as ?int` checks the text. The result is a plain `int`, or `null` when the text is not a whole
  number.
- A value you put into an `html` template with `{$name}` is escaped. The `<b>` is shown on the page and is not run.

There are more safe ways. A value in a database query goes in as a parameter, and the database
never reads it as SQL. `Core\Validate` checks a value against a rule, such as an email address.
`postAs` and `jsonAs` read a form or a JSON body into a class, and each field is checked.

## When the check fails

Passing a `tainted string` where a `string` is needed does not compile. The error is `E0401`, and it
points at the value. You fix it by choosing one of the safe ways above.

## Do and don't

- Do read input into a class with `postAs` or `jsonAs`. Declare text fields as `tainted string`.
- Do convert a number from the request with `as ?int` and handle the `null`.
- Do build HTML with `html` templates, so every value is escaped.
- Don't remove the `tainted` from a type to fix a compile error. Check the value.
- Don't use a tainted value as a file name. Choose the file name in your code.
