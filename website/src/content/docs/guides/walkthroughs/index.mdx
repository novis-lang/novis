---
title: Walkthroughs
covers: []
description: Short animations that show what Novis does while your program runs, one feature each.
---

Each walkthrough shows one thing that Novis does differently. It plays like a short video. It shows
the browser, your code and the server side by side, and a caption next to each step.

You can pause a walkthrough and go to the previous or next step. You can also play it in full screen.

- [Work after the response](/guides/walkthroughs/after-response/): your code sends an email after
  the browser has the page, in the same request.
- [Page now, slow parts later](/guides/walkthroughs/page-now/): the browser shows the page at once.
  Each slow part fills in when it is ready, in the same request.
