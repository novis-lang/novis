The guides show you how to use Novis. Each guide has small programs that you can run.

If you have not installed Novis yet, start with [Install](/install/).

The guides are written step by step. More detail is in
[Syntax](/syntax/), which shows how to write Novis code, and in [Reference](/reference/),
which lists every class and function.
