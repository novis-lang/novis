The Tour is a series of short steps. It starts with the
[Hello, World!](/install/hello-world/) program and ends with a small web application that you
run with `nvs serve`. Each step adds one idea to the program from the step before.

Every step has a program that you can copy and run with `nvs run`. The output is shown below
each program, so you can compare it with what you see.

You need `nvs` on your `PATH`. If you do not have it yet, read [Install Novis](/install/).

Start with [step 1: methods and types](/guides/tour/01-methods-and-types/).
