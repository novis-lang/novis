In Novis, every function is a method of a class. A method says the type of each parameter and the
type it returns. Save this program as `tour.nvs` and run it with `nvs run tour.nvs`:

<Snippet src="guides/tour/01-functions.nvs" />

`public static function` declares a method that you call on the class, with `Greeter::greeting`.
`.` joins two strings.

The compiler checks every call against the types. Change `9` to `"nine"` and run the program
again. It does not run, and `nvs` prints this error:

```txt
error[E0401]: expected `int`, found `string`
```

The error is found before the program starts. A web application with this mistake does not
start either, so no request ever reaches the broken code.

Read more in [Syntax: declaring a function](/syntax/functions/declaring/) and
[Syntax: declaring a class](/syntax/classes/declaring/).
