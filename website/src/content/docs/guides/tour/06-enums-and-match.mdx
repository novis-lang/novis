A task has a priority: low, normal or high. An enum is a type with a fixed list of values, so no
other priority can exist:

<Snippet src="guides/tour/06-enums-and-match.nvs" />

`Priority::High` is one case of the enum. The constructor gives `$priority` the default
`Priority::Normal`. The second task uses this default.

`match` compares the priority with each arm and returns the result of the arm that is equal. This
`match` has an arm for every case, so it needs no `default`.

Read more in [Syntax: enums](/syntax/values/enums/) and
[Syntax: match](/syntax/control-flow/match/).
