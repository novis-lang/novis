A web application sends HTML. In Novis you write it as an `html` template: HTML between backticks,
with `html` in front.

<Snippet src="guides/tour/09-html.nvs" />

`{$title}` is a hole. The value of `$title` goes into the HTML there, and it is escaped first. The
second title has `<b>` in it, and the page shows it as text. So a value from a user cannot add
a tag or a script to your page.

`{$items}` is a hole too. `$items` has the type `Core\Html\Markup`, which is HTML already, so it
goes in as it is. `+` joins two pieces of HTML.

The expression in a `{$…}` hole must start with a variable. For one that does not, such as a static
method call, write `<?= Pages::footer() ?>`. It is escaped in the same way.

Read more in [Syntax: string operators](/syntax/operators/string-operators/).
