`nvs serve` runs each request on its own. A request that crashes, runs out of memory or loops
forever stops only that request. The server and every other request keep running.

You can see the same thing in one program. This program starts a child program that fails:

This is the child program, `one-failure-child.nvs`:

<Snippet src="guides/why-novis/one-failure-child.nvs" />

The child calls itself until the call stack is too deep, and it stops with a `RecursionError`. The
parent gets the error as part of the result, and it keeps running.

A child also has its own copy of every static property. One request cannot change a value that
another request reads.

[Syntax: limits](/syntax/errors/limits/).
