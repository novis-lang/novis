A value that comes from outside the program is `tainted`. That includes a form field, a header and a
command-line argument. The compiler checks every place where your code uses the value:

<Snippet src="guides/why-novis/tainted-input.nvs" />

`as int` checks the text and gives a plain `int`. A hole in an `html` template escapes the text.
These are safe ways to use the value.

Using a tainted value as a plain `string` does not compile:

<Snippet src="guides/why-novis/tainted-input-error.nvs" />

The compiler finds the mistake before the program runs. No person has to find it in a code review.

Read more in [Syntax: tainted and secret strings](/syntax/values/tainted-and-secret/).
