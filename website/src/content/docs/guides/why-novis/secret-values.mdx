title: Secrets are never printed

---

import Snippet from '@components/Snippet.astro'

Passwords, tokens and API keys often end up in a log file by accident. In Novis you declare them as
`secret string`:

<Snippet src="guides/why-novis/secret-values.nvs" />

You can compare a secret string, and you can build a new string from it. The new string is secret too.

Printing a secret string does not compile:

```txt
error[E0790]: a `secret`-qualified value cannot be written by `echo`
  --> keys.nvs:3:6
  |
3 | echo $key, "\n";
  |      ^^^^ secret value written here
```

The same is true for an error message, a debug dump and JSON output. `Core\Secret::reveal` gives a
plain string when you really need one. You write the reason as its second argument.

Read more in [Syntax: tainted and secret strings](/syntax/values/tainted-and-secret/).
