Novis is a language for web servers and command-line programs. It is built to be safe and fast.
Each page in this section shows one feature that makes Novis different from other languages.

Every page has a short program and its output. You can copy the program and run it with `nvs run`.

**Safety**

- [HTML is escaped for you](/guides/why-novis/html-escapes/)
- [Input from outside is tainted](/guides/why-novis/tainted-input/)
- [Secrets are never printed](/guides/why-novis/secret-values/)
- [One failure stops one program](/guides/why-novis/one-failure/)

**Language design**

- [Null is checked when you compile](/guides/why-novis/no-null-surprises/)
- [Every conversion is checked](/guides/why-novis/checked-conversions/)
- [JSON with types](/guides/why-novis/typed-json/)
- [Text is Unicode](/guides/why-novis/unicode-strings/)

**Simplicity**

- [Tests are part of the language](/guides/why-novis/tests-in-code/)
- [Errors with a default in one line](/guides/why-novis/simple-errors/)
- [One standard library](/guides/why-novis/one-library/)
