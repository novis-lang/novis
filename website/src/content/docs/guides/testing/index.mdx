title: Testing your app
covers: []
description: Write tests next to your code, replace slow parts with test doubles, and test pages without a server.
---

Novis has a test runner built in. You write tests in Novis, and `nvs test` runs them. You do not
need to install a test framework.

- [Test doubles](/guides/testing/test-doubles/) shows how to replace a mail server, an HTTP API or
  the clock in a test.
- [Testing a page](/guides/testing/test-a-route/) sends a request to your routes without starting a
  server.

Read [Syntax: writing tests](/syntax/testing/writing-tests/) for every option of `#[Test]`.
