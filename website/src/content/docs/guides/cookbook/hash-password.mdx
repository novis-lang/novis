A website never stores a password. It stores a hash, which is a value made from the password that
cannot be turned back into it. This program makes a hash and checks two logins.

<Snippet src="guides/cookbook/hash-password/hash-password.nvs" />

`Core\Password::hash` returns a different hash each time, even for the same password. That is
why you check a login with `Core\Password::verify`, and never compare two hashes.

Read [Core\Password](/reference/core/password/) for `needsRehash`, which tells you when to make a
new hash.
