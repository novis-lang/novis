Each page here shows how to do one task. It has one short program and the output of that program.
Copy the part you need into your own code.

- [Read a JSON body](/guides/cookbook/read-json-body/) reads the JSON that a client sends into a
  class.
- [Validate a form](/guides/cookbook/validate-form/) checks each field of a contact form.
- [Page through database rows](/guides/cookbook/page-db-rows/) reads a table a few rows at a time.
- [Save an uploaded file](/guides/cookbook/upload-file/) writes a file from a form to a folder.
- [Call an HTTP API](/guides/cookbook/call-http-api/) sends a request to another server and reads
  the JSON reply.
- [Send a signed link](/guides/cookbook/signed-url/) makes a link that stops working after one hour.
- [Store a password](/guides/cookbook/hash-password/) saves a hash and checks a login against it.
- [Keep a value in a cookie](/guides/cookbook/signed-cookie/) stores a value the client cannot read
  or change.
- [Cache a slow result](/guides/cookbook/cache-value/) computes a value once and reuses it.
- [Schedule a job](/guides/cookbook/schedule-job/) runs a program every Monday morning.

Some tasks need a permission in `nvs.toml`, for example to write files. The page shows that file
when the task needs one.
