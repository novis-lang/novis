<div class="nv-features">
  <div class="nv-feature">
    <h3><span class="nv-feature-icon" aria-hidden="true">🛡</span> Memory-safe, request-isolated</h3>
    <p>
      Every request runs in its own isolate with its own memory budget. A crash, a leak or a runaway
      loop kills exactly one request — never the process, never a neighbour.
    </p>
  </div>
  <div class="nv-feature">
    <h3><span class="nv-feature-icon" aria-hidden="true">⚡</span> JIT-compiled to native code</h3>
    <p>
      No interpreter tier: every function compiles to machine code. Throwing an exception costs no
      more than returning a value — measured, and guarded by tests.
    </p>
  </div>
  <div class="nv-feature">
    <h3><span class="nv-feature-icon" aria-hidden="true">🔒</span> Security is structural</h3>
    <p>
      Tainted input cannot reach an SQL, HTML or shell sink without going through the one function
      that makes it safe. The compiler enforces it — not a code-review checklist.
    </p>
  </div>
  <div class="nv-feature">
    <h3><span class="nv-feature-icon" aria-hidden="true">🧭</span> One way to do things</h3>
    <p>
      ~450 Core members replace PHP's ~1,900 global functions. Eleven sort functions become one.
      Every API follows the same shape rules, so what you learn once applies everywhere.
    </p>
  </div>
  <div class="nv-feature">
    <h3><span class="nv-feature-icon" aria-hidden="true">🐘</span> PHP developers feel at home</h3>
    <p>
      Familiar syntax and observable behaviour, with the legacy removed. Every dropped PHP function
      has a named, mechanical replacement.
    </p>
  </div>
  <div class="nv-feature">
    <h3><span class="nv-feature-icon" aria-hidden="true">📖</span> Every decision is written down</h3>
    <p>
      More than a hundred architecture decision records document what Novis does, what it refuses to
      do, and the measurements behind both.
    </p>
  </div>
</div>
