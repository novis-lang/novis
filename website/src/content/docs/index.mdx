<Section
  title="The problem it is built for"
  lead="If every line of code on your servers was written by your team, most languages will do. Novis is for the case where that is not true."
>

A SaaS platform running logic its customers wrote. An agency hosting forty
clients in one fleet. A marketplace running plugins. A health or finance backend
where one leaked value is an incident you have to report.

In all of those, the dangerous code is code you cannot review, and the dangerous
data belongs to someone else. Most languages leave that to discipline: remember
to sandbox, remember not to log the token, remember to escape before the query.
Novis moves those three from discipline into the compiler.

</Section>

<Section
  title="Three things you get from the language itself"
  lead="Not a framework, not a linter, not a checklist. These are properties of the compiler and the runtime."

  <Card

    Run another file with a fresh heap, fresh globals and its own slice of the caller's budget —
    inside the same process. A crash, an endless loop or a memory blowout ends that one job. Nothing
    else notices.
  </Card>

  <Card
    kicker="Qualifiers"
    title="The compiler knows which values are dangerous"
    href="docs/safety/secret/"
    linkText="Secret and tainted values"
  >
    Mark a value <code>secret</code> and it cannot reach a log or an error page. Input arrives{' '}
    <code>tainted</code> and cannot reach a query, a shell or a template until something has cleaned
    it. Both are checked when the code compiles, not when it runs.
  </Card>

  <Card
    kicker="Concurrency"
    title="No coloured functions"
    href="docs/language/iteration/"
    linkText="How suspension works"
  >
    Any function may wait for I/O. There is no <code>async</code> keyword splitting your codebase in
    two, and no rule about which half may call which. One process serves many requests, each fully
    isolated.
  </Card>
</Cards>

<Section
  title="What it looks like"
  lead="Running another script as an isolated job. This is the shape of the feature; the exact spelling is still being pinned down."
>

```nvs
<?nvs
// Run a report as its own job: fresh heap, fresh globals, its own limits,
// and only the permissions we hand it.
$job = spawn script 'jobs/report.nvs' with(
    args:   ['month' => 7],
    limits: ['memory' => '256M', 'cpu_time' => '10s'],
    grants: ['fs.read' => '/srv/www/data'],
);

$result = await $job;

if (!$result->ok) {
    // The job failed. This request did not.
    Core\Log::warn($result->error->message);
}
```

The job cannot see this script's variables, cannot touch its open files, and
cannot read a directory we did not name. If it runs out of memory or time, it
ends — and the code above carries on at the next line.

</Section>

<Section
  title="The rest of the language"
  lead="Familiar in shape, deliberately different where it matters."
>

| | |
|---|---|
| **No build step** | Change a file and run it. Compilation happens on load and is cached. |
| **Actually compiled** | Native code, via Cranelift. There is no interpreter tier to fall back to. |
| **Memory-safe** | Written in Rust, with unsafe code confined to three audited modules. A runtime bug ends one request, not the process. |
| **Types everywhere** | Every parameter, property and variable declares its type. Conversions are explicit and throw rather than quietly producing `0`. |
| **Sandboxed extensions** | Extensions are WebAssembly components. One binary runs everywhere, and a hostile one harms one request. |
| **Familiar syntax** | The syntax starts from PHP 8.5, which makes it quick to read. It is an on-ramp, not a compatibility promise — Novis is a different language with a different type discipline, and PHP code is converted rather than dropped in. |

</Section>

<Section title="Where the project actually is" id="status">

Novis is **pre-alpha**. The compiler front end, the type system and the native
backend exist and are tested on three platforms; the language does not yet run
a program end to end. Nothing on this site is stable, and some of the syntax
shown here is still provisional.

We would rather say that on the front page than have you find out on page four.
