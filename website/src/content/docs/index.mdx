<div class="nv-features">
<div class="nv-feature">

### [Input from outside is tainted](/guides/why-novis/tainted-input/)

Text from a request cannot reach SQL, HTML or a shell command until you check it. The compiler
finds the mistake before the program runs.

</div>
<div class="nv-feature">

### [One failure stops one program](/guides/why-novis/one-failure/)

Each request runs on its own, with its own memory and limits. A request that crashes stops alone,
and the server keeps running.

</div>
<div class="nv-feature">

### [Secrets are never printed](/guides/why-novis/secret-values/)

A password or key is a `secret string`. Code that prints it or writes it to a log does not compile.

</div>
<div class="nv-feature">

### [HTML that escapes itself](/guides/why-novis/html-escapes/)

An `html` literal escapes every value you put into it. A comment from a user is shown as text, and
it never runs as a script.

</div>
<div class="nv-feature">

### [Every conversion is checked](/guides/why-novis/checked-conversions/)

`"12abc" as int` throws an error. `as ?int` gives `null`. Then your code can choose what to do next.

</div>
<div class="nv-feature">

### [Tests are part of the language](/guides/why-novis/tests-in-code/)

You write a test as a method with `#[Test]`. `nvs test` runs every test, each one on its own.

</div>
</div>
