## Novis

Novis is open source under the MIT license. The full text is in the file
<a href={LICENSE} {...externalLinkAttrs(LICENSE)}>LICENSE</a>.

## Code from other projects

`nvs` contains code from other open source projects. Each copy of `nvs` contains their licenses.
This command prints them:

```sh
nvs info --licenses
```

The release archives and the Docker image also contain the file
<a href={NOTICES} {...externalLinkAttrs(NOTICES)}>THIRD-PARTY-LICENSES.txt</a>, with the same text.
