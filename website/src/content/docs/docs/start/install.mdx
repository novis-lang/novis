## When this page becomes real

Running a program end to end is milestone **M3**, which is complete; a usable
distribution comes with the framework and the dependency story that follow it.
The [status page](../../../status/) tracks it, and is generated from the same
plan the team works against — so it is current even when this sentence is not.
