Serializes a value to a JSON string.

<MethodSignature id="Json.encode" />

## Description

`encode` turns scalars, arrays and participating objects into JSON text. A Novis array
maps naturally: a **list** becomes a JSON array, a **string-keyed array** becomes a
JSON object — and because Novis strings are valid UTF-8, the output is valid UTF-8
JSON with no `JSON_INVALID_UTF8_*` decisions to make. Of PHP's fifteen `JSON_*` flags,
two survived as options; the rest described problems Novis's type system removes.

Objects do **not** encode structurally: a class participates by implementing
`Core\Json\Codec` (`toJson(): mixed`), usually generated from the class's own declared
properties with the `#[Json\Derive]` attribute. There is no magic hook that silently
serializes whatever public properties happen to exist — what goes on the wire is
declared, renameable per field with `#[Json\Field]`, and visible in the class.

A **`secret` value cannot be encoded at all** — a password or token that reached the
value being serialized is a compile-time error, not a leaked log line later.

### Parameters

- **`$value`** (`mixed`) — the value to serialize: `null`, `bool`, numbers, `string`,
  arrays of encodable values, or objects with a `Codec`.

### Options

- **`pretty`** (`bool`) — human-readable output with two-space indentation. Defaults
  to `false`: compact, no insignificant whitespace.
- **`escapeUnicode`** (`bool`) — escape non-ASCII characters as `\uXXXX` for
  ASCII-only transports. Defaults to `false`: UTF-8 passes through verbatim (PHP's
  `JSON_UNESCAPED_UNICODE`, here the default because the output is known-valid UTF-8).

## Return value

Returns `string`: the JSON text. Key order in objects follows the array's insertion
order — encoding is deterministic.

## Errors

Throws when the value cannot be represented: a `NaN` or infinite `float` (JSON has no
spelling for them), or an object without a `Codec`. A `secret` anywhere in the value
does not compile.
