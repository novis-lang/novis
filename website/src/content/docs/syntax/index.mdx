These pages show how to write Novis code. Each page explains one part of the language
with an example that you can run.

If you are new to Novis, read [Start here](/syntax/start-here/) first. Then read the groups in
this order, or go to the one you need:

- [Basics](/syntax/basics/files-and-statements/): files, statements, comments, variables and
  constants.
- [Values and types](/syntax/values/numbers/): numbers, strings, arrays, `null`, enums, and how to
  convert and test types.
- [Operators](/syntax/operators/arithmetic/): arithmetic, comparison, `??`, string operators and
  the pipeline `|>`.
- [Control flow](/syntax/control-flow/if/): `if`, `match`, `switch`, loops and generators.
- [Errors](/syntax/errors/throw-and-catch/): `throw`, `try`, `catch`, the error classes and the
  limits of a program.
- [Functions](/syntax/functions/declaring/): declaring and calling functions, parameters and
  closures.
- [Classes and objects](/syntax/classes/declaring/): classes, properties, methods, interfaces and
  shapes.
- [Programs and files](/syntax/programs/namespaces/): namespaces, `autoload`, `require` and file
  paths.
- [Concurrency](/syntax/concurrency/tasks/): tasks that run at the same time, channels and separate
  programs.
- [Attributes](/syntax/attributes/writing-and-reading/): data on a declaration, JSON, routes and
  commands.
- [Testing](/syntax/testing/writing-tests/): tests, fixtures, data rows and assertions.

To look up a single class or function, use [Reference](/reference/).
