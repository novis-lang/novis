`foreach ($array as var $value)` runs the body once for each element. `$value` is the element for
that pass.

<Snippet src="syntax/foreach/01-foreach.nvs" />

- Each variable in the header has a type or `var`. `as $v` alone does not compile.
- `var` gives the variable the element type of the array. For the key, `var` gives `string`.
- The key of an array is always a `string`, also when it looks like a number.
- `inout var $v` writes each change to `$v` back into the array.
- The loop walks a copy of the array. Adding or removing elements in the body does not change which
  elements the loop visits. An `inout` loop walks the array itself.
- To convert the value first, put it in parentheses: `foreach (($m as array<int>) as var $v)`.

## Objects and collections

`foreach` also takes an object that implements `Iterable<T>` or `Iterator<T>`. These objects have
no keys, so you write only the value. [Iterators and generators](/syntax/control-flow/iterators/)
shows how to write one.

<Snippet src="syntax/foreach/02-collections.nvs" />

- `Core\ObjectSet`, `Core\Heap` and `Core\Task\Channel` give their values.
- `Core\ObjectMap` gives its keys. Use `get` to read the value for a key.
- A loop over a `Core\Task\Channel` ends when the channel is closed.
- `Core\Arr::from` takes anything `foreach` takes, and returns an array with the keys `0`, `1`,
  `2`, and so on.

## Use this when you need the position as a number

`foreach` gives string keys. When you need a counter that you can add to, use a
[`for` loop](/syntax/control-flow/loops/).

## Do and don't

- Do use `var` for the loop variable unless you need a wider type.
- Do use `inout` to change the elements of an array in place.
- Don't add elements to the array inside the loop and expect the loop to visit them.
- Don't write a key variable for an object. Only arrays have keys.
