`if (condition)` runs its body when the condition is true. `elseif` tests another condition, and
`else` runs when no condition before it was true.

## Use this when you choose between values

When each branch only picks a value, [`match`](/syntax/control-flow/match/) is shorter. It returns
the value, so you assign it once.

## Do and don't

- Do use braces around every body that is longer than one short line.
- Do declare a variable before the `if` when both branches set it.
- Don't write `if (...):` with `endif;`. Novis only has the brace syntax.
- Don't declare the same variable again in a second block. Assign it instead.
