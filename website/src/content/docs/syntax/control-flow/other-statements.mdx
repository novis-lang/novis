`echo` writes values to the output. `unset` removes entries from an array. `exit` ends the program.

<FeatureSection examples="lang/statements/statement-forms-that-do-not-parse" heading="Statements Novis does not have" id="statements-novis-does-not-have" />

| Statement | Use instead |
|---|---|
| `goto` and labels | a loop, an early `return`, or a `bool` variable |
| `declare(...)` | nothing. Every file is already strict |
| `if (...):` with `endif;`, `endwhile;` and the other `end` forms | braces |
| `global $x;` | a parameter, or a `static` property |
| `static $n = 0;` inside a method | a `private static` property |
| `list($a, $b) = ...` | `[int $a, int $b] = ...` |
| `include`, `require_once` | `require` |
| `class`, `interface`, `enum`, `namespace` or `use` inside a body | write it at the top level of the file |

## Use this when you stop a script with an error

`exit(1)` ends a command line program with the status `1`. When the cause is an error that code
around it can handle, throw an error instead.

## Do and don't

- Do put `"\n"` at the end of an `echo` when you want a new line.
- Do assign `null` to clear a nullable variable.
- Don't use `unset` on a variable. It does not compile.
- Don't call `exit` inside a library method. Throw an error, so the caller can handle it.
