A method that contains `yield` is a generator. It returns an `Iterator<T>`. A class works in
`foreach` when it implements `Iterable<T>` or `Iterator<T>`.

<FeatureSection examples="lang/iteration/generators" heading="Generators" id="generators" />

<FeatureSection examples="lang/iteration/the-two-interfaces" heading="Iterable and Iterator" id="iterable-and-iterator" />

`Iterator<T>` has two methods. You can write them yourself, without `yield`.

| Method | What it does |
|---|---|
| `advance(): bool` | moves to the next value. It returns `false` when there are no more values |
| `current(): T` | returns the value that `advance()` moved to |

`Iterable<T>` has one method, `iterate(): Iterator<T>`.

<FeatureSection examples="lang/iteration/what-does-not-exist" heading="What does not exist" id="what-does-not-exist" />

## Use this when you need full control

A generator is the short way to write an `Iterator<T>`. Write the class with `advance()` and
`current()` yourself when the cursor needs methods or properties of its own.

## Do and don't

- Do use a generator to read a large or endless list one value at a time.
- Do implement `Iterable` when the same object must work in more than one loop.
- Don't loop twice over one generator. Call the method again to get a new one.
- Don't write `$obj[0]` on an object. Give the class a method that returns the element.
