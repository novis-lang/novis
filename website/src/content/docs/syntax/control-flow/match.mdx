`match (value) { ... }` compares the value with each arm, in order. It returns the result of the
first arm that is equal. `match` is an expression, so you can assign it or pass it to a function.

<Snippet src="syntax/match/01-match.nvs" />

- An arm is a list of values, then `=>`, then one expression. `1, 2 => "low"` matches `1` or `2`.
- `match` compares with `==`. The value in parentheses after `match` is the subject. An arm value that can never be equal to it does not compile.
- `default` is used when no other arm matches, wherever you write it.
- No arm matches and there is no `default`: `match` throws a `LogicError`.
- The result of an arm is one expression. It cannot be a block of statements.

## Use this when you test conditions in order

`match (true)` checks each arm's condition, in order. It returns the result of the first condition
that is true. This replaces a long chain of `elseif`.

`match` also works on enum cases. The compiler does not check that the arms list every case, so a
case with no arm throws the same `LogicError`. See [Enums](/syntax/values/enums/).

## Do and don't

- Do use `match` when each branch only gives a value.
- Do write a `default` arm unless the arms list every possible value.
- Don't use `match` to run several statements in each branch. Use `if` or `switch`.
- Don't catch the `LogicError` of a missing arm to handle normal values. Add the arm or `default`.
