A comment is a note for the person who reads the code. The program runs the same way without it.
A doc comment, written with `///`, describes a declaration for the people who call it.

## Do and don't

- Do write `///` above each public class and method.
- Do write `//` for a short note inside a function.
- Don't write `/** ... */` above a declaration. Write `///` instead.
- Don't leave an empty line between a `///` comment and its declaration. That does not compile.
