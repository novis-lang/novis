A constant is a value that never changes. Every constant belongs to a class. There are no global
constants.

<FeatureSection examples="lang/classes/constants-and-class" heading="Class constants and ::class" id="constants" />

## Do and don't

- Do use a constant for a fixed limit or a fixed label, such as `MAX_ITEMS`.
- Do write constant names in `SCREAMING_SNAKE_CASE`.
- Don't use a constant for a value that comes from configuration. Read it when the program runs.
