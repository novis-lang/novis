Every variable has a type. You declare a variable once, with its type or with `var`. After that,
you assign new values without the type.

<FeatureSection examples="lang/types/every-binding-has-a-type" heading="Declaring a variable" id="declaring-a-variable" />

## Do and don't

- Do write the type when it helps the reader, such as for a function result.
- Do use `var` when the value already shows the type.
- Don't use one variable for values of different types. Declare a second variable.
- Don't use `var` for an empty array. Write `array<string> $names = [];`.
