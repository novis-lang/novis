`#[Core\Json\Derive]` in front of a class lets you convert its objects to and from JSON.
`Core\Json::encode` writes an object as JSON text. `Core\Json::decodeAs<T>` builds an object of
the class `T` from JSON text.

<FeatureSection examples="lang/attributes/core-json-derive-and-core-json-field-a-class-with-a-json-codec" heading="Core\Json\Derive and Core\Json\Field" id="core-json-derive" />

## Do and don't

- Do write a constructor that takes every property, with the same names and types.
- Do catch `ParseError` around `decodeAs` when the text comes from a user.
- Do use `#[Core\Json\Field(skip: true)]` for a value that is only a cache.
- Do declare a password that a request sends as `secret tainted string`. The decoder fills it, and
  encoding the class does not compile.
- Do add `#[Core\Json\KeepKeyOrder(reason: '...')]` when another program reads the keys in their
  order. `nvs code order` then keeps the properties of the class in the order you wrote them.
