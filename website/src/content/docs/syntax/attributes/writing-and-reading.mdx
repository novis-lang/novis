An attribute is a small piece of data that you write in front of a declaration. You declare it
first, with its name, the places it may be written and its fields:
`attribute Route on method { path: string }`. Then you write it with `#[`, as in
`#[Route(path: '/users')]`. An attribute does nothing by itself. Your program reads it back with
`Core\Attributes`.

These are the names Novis reads: `Core\Json\Derive`, `Core\Json\Field`, `Core\Route`,
`Core\Access`, `Core\Query`, `Core\Api`, `Core\Command`, `Core\Option` and the testing attributes.
The next pages show what each one does.

## Do and don't

- Do list only the places where your program reads the attribute after `on`. Any other place does
  not compile.
- Do declare an attribute inside a base class when only its subclasses use it. Other classes then
  cannot use it.
- Do write a `///` comment above each field. The editor shows it when you type the field's name.
- Don't put a variable or a function call in an attribute. Use a class constant.
- Don't name your own attribute after a Novis attribute. The program compiles, but the code is harder
  to read.
