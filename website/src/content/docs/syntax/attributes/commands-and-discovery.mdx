`Core\Program::implementing<I>()` returns one new object of every class that implements `I`. You
do not need to list the classes yourself. The compiler finds them while it compiles.

`Core\Command::run()` returns the exit status of the command. Its
[reference page](/reference/core/command/run/) has more examples.

## Do and don't

- Do pass what a class needs through the methods of `I`. Its constructor takes no arguments.
- Do use `implementingWith` when you need the attribute of each class. `implementing` gives only
  the objects, without their attributes.
- Do declare a positional argument `tainted string`, and check it before you use it.
- Do call `Core\Command::run()` once, at the top level of the program, and pass its result to `exit`.
