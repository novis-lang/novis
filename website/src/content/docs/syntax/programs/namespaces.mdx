A namespace is the first part of a class name. `App\Text\Greeter` is the class `Greeter` in the
namespace `App\Text`. `autoload` finds the file of a class from its name, so a program never names
the file.

## Do and don't

- Do give each class its own file, in the folder its namespace names.
- Do write one `autoload` line in the file that starts your program.
- Do write `use` for a class you name often, and the full name for one you name once.
- Don't use `require` to load a class. Use `autoload`, so the file is read only once.
- Don't start a name with a backslash. A name with a backslash in it is already the full name.
