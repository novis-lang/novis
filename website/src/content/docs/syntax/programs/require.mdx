`require 'config.nvs'` runs another file at the place where you write it. The value of `require`
has the type `mixed`. Text converted from a `mixed` value is tainted, so `as array<string>` gives
an `array<tainted string>`.

<FeatureSection examples="lang/programs/require-run-another-file-in-this-frame" heading="require" id="require" />

## Do and don't

- Do use `require` for a file that returns a value, such as settings.
- Do convert the result with `as` right away.
- Don't use `require` for a file that only declares classes. Use `autoload`, which reads it once.
- Don't expect a variable from the other file. Return the value from that file.
