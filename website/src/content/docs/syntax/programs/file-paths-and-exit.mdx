A relative path in quotes starts at the folder of the file you write it in. So a program reads the
same file from a terminal and from a server. `exit` ends a program before its last line.

<FeatureSection examples="lang/programs/file-paths-a-relative-path-starts-at-the-folder-of-its-file" heading="File paths" id="file-paths" />

A program may read a file only if its `nvs.toml` allows it. The `nvs.toml` of these examples has
`read = ["."]` under `[capabilities.fs]`. `Core\Path::fromCwd` joins a path to the folder the program was started
from. Use it for a path typed on the command line. It throws an error while the program handles a
web request.

<FeatureSection examples="lang/programs/ending-a-program" heading="Ending a program" id="ending-a-program" />

## Do and don't

- Do write a file path in quotes, relative to the file that uses it.
- Do use `Core\Path::join` with `Core\Path::thisDir()` for a path you build from parts.
- Do use `exit(1)` or another status that is not 0 when a command-line program fails.
- Don't use `Core\Path::fromCwd` in code that handles web requests.
- Don't write `die`. It does not compile.
