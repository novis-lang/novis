An anonymous function is a function you write with `fn` and store in a `callable` variable:
`callable $double = fn(int $x): int => $x * 2;`. Usually it has no name. It has a name only when
it calls itself.

<FeatureSection examples="lang/expressions/anonymous-functions" heading="fn" id="fn" />

How to call a `callable` is on the page [Calling a function](/syntax/functions/calls/).

## Do and don't

- Do keep an anonymous function short. Write a method when it needs many lines.
- Do write a method when other code also needs to call the function.
- Do write the return type on an anonymous function with a block body.
- Don't change an outside variable after you create an anonymous function and expect it to use the new value. The function has a copy.
- Don't write `function () {}`. It does not compile. Use `fn`.
