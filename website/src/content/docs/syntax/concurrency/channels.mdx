A channel is a queue between tasks. One task puts values in with `send`. Another task takes them
out with `foreach`.

<FeatureSection examples="lang/concurrency/core-task-channel-t-a-bounded-queue-between-tasks" heading="Core\Task\Channel" id="core-task-channel" />

## Do and don't

- Do call `close` when the sending task is done. Without it, the loop waits forever.
- Do pick a small capacity. A full channel slows the sender down, so the queue stays small.
- Don't send after `close`. It stops the whole program.
