`tainted` means the value comes from outside the program, such as a form or a command-line argument.
`secret` is for passwords, tokens and keys. The compiler checks both words.

<FeatureSection examples="lang/types/qualifiers-tainted-and-secret" heading="tainted and secret" id="tainted-and-secret" />

## Do and don't

- Do declare request input as `tainted string`.
- Do convert tainted input with `as int` or an enum when you can.
- Do declare passwords and API tokens as `secret string`.
- Don't call `Core\Secret::reveal` only to print a value. Write a reason that says why it must be
  shown.
