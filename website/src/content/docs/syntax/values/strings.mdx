A `string` is text. Write it in double quotes, and you can write a variable inside it. Binary data
has its own type, `bytes`.

<FeatureSection examples="lang/types/values-written-in-the-code" heading="Values written in the code" id="values-written-in-the-code" />

`<<<'TXT'`, with the marker in single quotes, is a nowdoc. It prints `$name` as written.

<FeatureSection examples="lang/types/text-string-and-bytes" heading="Text and bytes" id="text-and-bytes" />

## Do and don't

- Do use double quotes and interpolation for short messages.
- Do use `Core\Str` methods to measure and cut a string.
- Don't do arithmetic on a string. `"3" * 2` does not compile. Convert it first: `"3" as int`.
- Don't keep binary data in a `string`. Use `bytes`.
