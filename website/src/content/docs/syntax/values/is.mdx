`$value is Cat` is `true` when `$value` is a `Cat` object. Inside the branch where the test is true,
the variable has the type `Cat`.

## Testing for int or string

`is` also tests for a type such as `int` or `string`. `$value is int` is `true` only when `$value`
is an `int`. The string `"7"` is not an `int`. To accept `"7"` as a number, convert it:
`($value as ?int) != null`.

A `mixed` value may come from outside the program. So after `$value is string`, `$value` has the
type `tainted string` (text that the program must not trust yet). See
[Tainted input](/guides/how-to-use/tainted-input/).

## Do and don't

- Do test with `is` before you call a method that only one class has.
- Do use `match (true)` for three or more tests.
- Don't convert with `as Cat` when the value may be another class. `as` throws an error then.
