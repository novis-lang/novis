`?T` is a `T` or `null`. A type without `?` can never be `null`. `$a ?? $b` gives `$a` when it is
not `null`, and `$b` when it is. To use the value itself, test it with `== null` or `!= null`
first. [Type tests with is](/syntax/values/is/) shows how a test changes the type.

`$user->name` on a `?User` does not compile until you test `$user`. `$user?->name` needs no test.
When `$user` is `null`, the result is `null`.

## Do and don't

- Do use `?T` for a value that can be missing, such as an optional setting.
- Do give a default with `??` when one makes sense.
- Don't use `?T` when the value is always there. Every reader then has to handle `null`.
