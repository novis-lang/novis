An enum is a type with a fixed list of named cases. Each case is a whole number.

<Snippet src="syntax/enums/01-declare.nvs" />

- The cases are separated by commas. Case names start with a capital letter.
- `enum Size: uint { ... }` makes every case a `uint`. Without `: uint`, every case is an `int`.
- Two cases can have the same number.
- An enum contains only cases. It has no methods and no constants.

## Convert between a case and a number

`as int` gives the number of a case. `as Status` gives the case for a number.

<Snippet src="syntax/enums/02-from-a-number.nvs" />

- `echo Status::Draft;` and `Status::Draft as string` do not compile. Write
  `(Status::Draft as int) as string`.
- `==` and `!=` compare two cases of the same enum. To sort cases, compare their numbers.
- `Status::Draft == 0` does not compile. A case is not a plain number.

## Use this when you need a name or a list of cases

A case has no `->name` and an enum has no `cases()` method. Write a class with a `match` for the
names and a method that returns the list.

<Snippet src="syntax/enums/03-names-and-lists.nvs" />

A `match` with no arm for the value and no `default` throws an error. A `switch` over an enum works
too.

## Use this when only some cases are allowed

A type can list some cases of an enum: `Mode::Read|Mode::Write`.

<Snippet src="syntax/enums/04-some-cases.nvs" />

Passing `Mode::Delete` to `Files::open` does not compile. `as Mode::Read|Mode::Write` throws an error
when the value is a different case.

## Enums from Core

Many `Core` methods take an enum from `Core`, such as `Core\Order`, `Core\RoundMode` or
`Core\Weekday`. They work like your own enums. [Reference](/reference/core/) lists every one.

<Snippet src="syntax/enums/05-core-enum.nvs" />

## Do and don't

- Do use an enum for a fixed set of choices, such as a status or a mode.
- Do use `as ?Status` for a number from outside the program. You then handle `null`.
- Don't use a case as an array key. Use its number: `$names[$status as int]`.
- Don't add behaviour to an enum. Put it in a class that takes the enum.
