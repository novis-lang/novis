An enum is a type with a fixed list of named cases. Each case is a whole number.

<FeatureSection examples="lang/enums/declaring-an-enum" heading="Declaring an enum" id="declaring-an-enum" />

When only one class uses an enum, declare the enum inside that class. When several classes use it,
declare it at the top level of the file.

Many `Core` methods take an enum from `Core`, such as `Core\Arr::Order`, `Core\RoundMode` or
`Core\Time\DateTime::Weekday`. They work like your own enums. [Reference](/reference/core/) lists every one.

<FeatureSection examples="lang/enums/core-enums" heading="Enums from Core" id="enums-from-core" />

## Do and don't

- Do use an enum for a fixed set of choices, such as a status or a mode.
- Do use `as ?Status` for a number from outside the program. You then handle `null`.
- Don't use a case as an array key. Use its number: `$names[$status as int]`.
- Don't add behaviour to an enum. Put it in a class that takes the enum.
- Do declare an enum inside the class that uses it. Write `Status`, not `OrderStatus`.
