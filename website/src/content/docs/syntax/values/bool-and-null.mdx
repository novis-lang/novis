A `bool` is `true` or `false`. `null` means "no value", and only a type that starts with `?` can be
`null`. The page [Nullable types](/syntax/values/nullable/) explains `?` and `??`.

<FeatureSection examples="lang/types/truthiness" heading="Truthy and falsy values" id="truthy-and-falsy-values" />

## Do and don't

- Do compare with `== null` when you mean "has no value". `0` and `""` count as false too.
- Do use `as bool` when you store the result of a test in a `bool` variable.
- Don't use `true as int`. It does not compile. Write `$flag ? 1 : 0`.
