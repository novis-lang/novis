A `bool` is `true` or `false`. `null` means "no value", and only a type that starts with `?` can be
`null`.

<Snippet src="syntax/bool-and-null/01-bool-and-null.nvs" />

`int $count = null;` does not compile. Write `?int $count = null;`. The page
[Nullable types](/syntax/values/nullable/) explains `?` and `??`.

## Use this when a condition tests a value that is not a bool

`if`, `while`, the `?:` operator, `&&`, `||` and `!` accept any value. These values count as false:
`false`, `0`, `0.0`, `""`, `"0"`, an empty array, empty `bytes` and `null`. Every other value counts as
true.

<Snippet src="syntax/bool-and-null/02-truthiness.nvs" />

`"0.0"` and `" "` count as true. Every object and every enum case counts as true.

Only conditions do this. A `bool` variable, parameter or return value needs `as bool`.

## Do and don't

- Do compare with `== null` when you mean "has no value". `0` and `""` count as false too.
- Do use `as bool` when you store the result of a test in a `bool` variable.
- Don't use `true as int`. It does not compile. Write `$flag ? 1 : 0`.
