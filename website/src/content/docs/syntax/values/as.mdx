`value as T` converts a value to the type `T`. If the conversion is not possible, it throws an error.
`as ?T` gives `null` instead. To test the class of an object, use [`is`](/syntax/values/is/).

<FeatureSection examples="lang/types/the-conversion-operator-as" heading="The as operator" id="the-as-operator" />

## Converting a mixed value to text

A `mixed` value may come from outside the program, for example from a request. So text you take
out of it is tainted (text that the program must not trust yet).

- `$value as string` gives a `tainted string`, and `$value as ?string` gives a `?tainted string`.
- `$value as array<string>` gives an `array<tainted string>`.
- `$value as int`, `as float` and `as bool` give a plain `int`, `float` or `bool`.

[Tainted input](/guides/how-to-use/tainted-input/) shows how to use tainted text safely.

## Do and don't

- Do use `as ?int` with `??` for input that may be wrong: `($input as ?int) ?? 0`.
- Do use `as int` when wrong input is an error.
- Don't write `(int)$value`. It does not compile. Write `$value as int`.
- Don't round with `as int`. Use `Core\Math::round` first.
