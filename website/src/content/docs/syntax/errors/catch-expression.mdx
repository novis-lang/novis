`Repo::get($id) catch (IOError $e) => 0` returns the result of `Repo::get($id)`. If that call
throws an `IOError`, the result is `0`. It is the short form of a `try` block that only needs a value.

<FeatureSection examples="lang/statements/catch-as-an-expression" heading="catch after an expression" id="catch-as-an-expression" />

## Use this when you need statements

Write a `try` block when the error needs more than one value: a log line, a cleanup step, or a
`return`. See [throw, try and catch](/syntax/errors/throw-and-catch/).

## Do and don't

- Do name the class you expect: `catch (IOError $e) => 0`.
- Do use this form for a default value, such as `0` or `null`.
- Don't write `catch (Throwable) => value`. It hides every error, also the bugs. The compiler warns about it.
- Don't put a `return` in an arm. Use the `try` block.
