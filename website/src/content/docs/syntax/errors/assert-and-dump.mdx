A `Core\Test::assert...` method that fails throws `Core\Test\Failure`. `Core\Debug::render` returns
a readable view of any value as a string.

<Snippet src="syntax/assert-and-dump/01-assert-and-dump.nvs" />

- `Core\Test\Failure` extends `Throwable` directly. A `catch (RuntimeError $e)` does not catch it.
- In a test method, the test runner catches it and reports the test as failed.
- Outside a test, it is a normal error that ends the program if nothing catches it.
- `Core\Debug::render` shows control characters, such as a tab, as `\t`.
- A very deep or very long value is shortened. A `secret` property is hidden.

## Use this when the output must stay clean

`Core\Debug::dump($value)` writes the same view to standard error. It never goes into the normal
output, so a web page or a captured output does not change.

## Do and don't

- Do use `Core\Debug::dump` while you look for a bug.
- Do use `Core\Debug::render` when you need the text, for example in a log line.
- Don't catch `Core\Test\Failure` in a test to hide a failure.
- Don't print `render` output to a web page. Use it for logs and debugging.
