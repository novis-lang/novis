`throw new IOError("...")` stops the current function and throws an error. `try { ... }` runs a
block, and a `catch (IOError $e) { ... }` after it runs when that block throws an `IOError`.
`finally { ... }` runs last, whatever happened.

The classes you can throw are on the page [Error types](/syntax/errors/error-types/).

## Use this when you only need a value

A `try` block is the long form. When you only want a fallback value, write `catch` as an
expression: [catch as an expression](/syntax/errors/catch-expression/).

## Do and don't

- Do put the narrow classes first. A `catch (Throwable $e)` first catches everything.
- Do catch the class you expect, such as `IOError`. Then a bug still shows as an error.
- Do use `finally` to close or clean up something, whatever happens in the `try`.
- Don't use `return` in `finally`. It does not compile.
- Don't write `Exception`. It does not exist. Use `RuntimeError`, `LogicError` or `Throwable`.
