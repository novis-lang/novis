A test is a method with the attribute `#[Test]`. You can write it in any class. `nvs test file.nvs`
runs every test in the program.

A test can also get values from a fixture or a data row. The page
[Fixtures, data rows and assertions](/syntax/testing/fixtures-and-assertions/) explains them.

## Use this when you check your own code

Write `#[Test]` methods to test the classes of your program. Use a `.nvst` file only to check the
exact text a whole program prints.

## Do and don't

- Do use `at:` and `seed:` in a test that reads the time or random numbers.
- Do give every `skip:` a reason that says when the test will run again.
- Do give a slow test a `tags:` label, such as `"slow"`. `nvs test --skip-tag slow` then runs every
  other test.
- Don't use `retries:` to hide a bug. A flaky test is always shown in the report.
- Don't share state between tests through a static property. Each test starts fresh.
