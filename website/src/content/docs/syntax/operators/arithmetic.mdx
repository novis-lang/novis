`+`, `-`, `*`, `/`, `%` and `**` work on the four number types: `int`, `uint`, `float` and
`decimal`.

<Snippet src="syntax/arithmetic/01-arithmetic.nvs" />

| Operator | What it does |
|---|---|
| `+` `-` `*` | add, subtract, multiply |
| `/` | divide. `7 / 2` is `3.5`, and `6 / 3` is `2` |
| `%` | the remainder after division. It works on whole numbers only |
| `**` | the power. `2 ** 10` is `1024` |

Arithmetic needs numbers on both sides. `"3" * 2` does not compile. Write `($s as int) * 2`.

A value that can be `null`, such as a `?float`, does not compile either. Test it first with
`if ($a != null)`, or give it a default with `??`: `($a ?? 0.0) + 1.5`.

## Errors

<Snippet src="syntax/arithmetic/02-errors.nvs" />

These operations throw an `ArithmeticError`:

- a division by zero, with `/` or `%`
- a result that is too big or too small for its type
- a negative power of a whole number, such as `2 ** -1`

`Core\Math::fdiv` divides two `float` values and returns `INF` for a division by zero.

## Changing a variable

<Snippet src="syntax/arithmetic/03-assignment.nvs" />

- `=` stores a value. `$a = $b = 3` stores `3` in both variables.
- `+=`, `-=`, `*=`, `/=`, `%=`, `**=` and `.=` change the variable that is already there.
- `++` adds one and `--` subtracts one. `$n++` gives the old value, and `++$n` gives the new value.
- An operator like `+=` never changes the type of the variable. So `$n /= 2` does not compile
  when `$n` is an `int`.

## Use this when you work with bits

`&`, `|`, `^`, `~`, `<<` and `>>` work on the bits of an `int` or a `uint`. `6 & 3` is `2`, and
`1 << 3` is `8`. Both sides need the same type.

## Do and don't

- Do use `Core\Math::intDiv` when you need a whole number from a division.
- Do catch `ArithmeticError` where a divisor comes from user input.
- Don't mix `int` and `uint` in one expression. Convert one side with `as` first.
- Don't use `/=` on an `int` variable. Use a `float` variable.
