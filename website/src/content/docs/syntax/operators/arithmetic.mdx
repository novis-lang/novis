`+`, `-`, `*`, `/`, `%` and `**` work on the four number types: `int`, `uint`, `float` and
`decimal`. `=` and the operators like `+=` store a value in a variable.

<FeatureSection examples="lang/expressions/arithmetic" heading="Arithmetic" id="arithmetic" />

`Core\Math::fdiv` divides two `float` values and returns `INF` for a division by zero.

<FeatureSection examples="lang/expressions/assignment" heading="Changing a variable" id="assignment" />

## Use this when you work with bits

`&`, `|`, `^`, `~`, `<<` and `>>` work on the bits of an `int` or a `uint`. `6 & 3` is `2`, and
`1 << 3` is `8`. Both sides need the same type.

## Do and don't

- Do use `Core\Math::intDiv` when you need a whole number from a division.
- Do catch `ArithmeticError` where a divisor comes from user input.
- Don't mix `int` and `uint` in one expression. Convert one side with `as` first.
- Don't use `/=` on an `int` variable. Use a `float` variable.
