`==` checks if two values are equal, and `!=` checks if they are different. Neither operator
converts a value to another type. `&&`, `||` and `!` combine conditions.

## Dates, times and durations

`==` compares a value from `Core\Time` by its value. Two `Date` objects for the same day are equal,
and `90m == 1h30m` is `true`. This works for `Date`, `TimeOfDay`, `Instant`, `Duration`, `Zone` and
`DateTime`. Objects of your own classes are equal only when they are the same object.

A `DateTime` is compared by its moment. 10:00 in `Europe/Berlin` and 09:00 in `Europe/London` on the
same day are equal, even though they print different text. `<`, `<=`, `>` and `>=` also work
on two `DateTime` values, so you can put events from different time zones in order.

## Use this when you compare strings

`<` and `>` do not work on strings. `Core\Str::compare($a, $b)` returns `-1`, `0` or `1`.

## Do and don't

- Do test a nullable value with `!= null &&` before you use it on the same line.
- Do use `Core\Str::compare` to sort strings.
- Don't write `and`, `or` or `xor`. Write `&&` for `and` and `||` for `or`. For `xor`, write `!=`
  between two `bool` values.
- Don't write `===`. `==` already compares without converting.
