`==` checks if two values are equal, and `!=` checks if they are different. Neither operator
converts a value to another type. `&&`, `||` and `!` combine conditions.

## Use this when you compare strings

`<` and `>` do not work on strings. `Core\Str::compare($a, $b)` returns `-1`, `0` or `1`.

## Do and don't

- Do test a nullable value with `!= null &&` before you use it on the same line.
- Do use `Core\Str::compare` to sort strings.
- Don't write `and`, `or` or `xor`. Write `&&`, `||`, and `!=` between two `bool` values.
- Don't write `===`. `==` already compares without converting.
