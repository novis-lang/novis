`.` joins two values into one string. `.=` adds a value to the end of a string variable.

## Use this when you build a string from many values

A double-quoted string can contain variables. `"Hello $name"` and `"Hello {$user->name}"` are
often easier to read than many `.` operators. [Strings and interpolation](/syntax/values/strings/)
shows all the ways to write a string.

## Do and don't

- Do use interpolation for short messages with a few values.
- Do use `.=` to build a string in a loop.
- Don't use `+` to join strings. `+` works on numbers only.
- Don't use `.` to build HTML. Use an `html` template. It escapes each value for you.
