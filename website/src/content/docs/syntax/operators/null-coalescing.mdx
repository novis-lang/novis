`$a ?? $b` gives `$a` when it is not `null`. Otherwise it gives `$b`.

<FeatureSection examples="lang/expressions/and-the-ternary" heading="??, ?:, ?-> and the ternary" id="and-the-ternary" />

## Use this when you count or collect values in an array

`$byStatus[$status] ??+= 1` counts each status, even the first time. The page
[Arithmetic and assignment](/syntax/operators/arithmetic/#assignment) explains `??+=`.

## Do and don't

- Do use `??` for a default value, and `??=` to set a value once.
- Do use `??+=` to count with an array.
- Don't put a nested ternary on one line. Use parentheses, or a `match`.
- Don't write `$n ?? 0 + 10`. `+` runs first. Write `($n ?? 0) + 10`.
