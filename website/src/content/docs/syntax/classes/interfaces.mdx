An interface is a list of methods. A class that implements the interface must have every method
in the list. Then you can use the class wherever the interface type is needed.

<Snippet src="syntax/interfaces/01-interface.nvs" />

- A class can implement many interfaces: `class Person implements Greets, Counts`.
- A missing method is a compile error. The message names the method and the interface.
- A method with a body is a default method. The class gets it, and it can replace it.
- A class that replaces a default method calls the default as `Greets::greet()`.
- An interface can have `private` helper methods, typed constants and `static` methods.
- An interface can extend another interface: `interface Titled extends Named`.
- An interface has no properties. Write a method instead, or a constant if the value is fixed.

## Forwarding with by

`implements Greets by $voice` writes every `Greets` method for you. Each one calls the same method
on the object in the property `$voice`.

<Snippet src="syntax/interfaces/02-by.nvs" />

- The property must be declared in the class, and its type must be a class or interface that
  implements `Greets`. It cannot be nullable.
- A method you write yourself is used in place of the forwarded one.
- Use `by` to add to a `final` class. Store an object of that class in a property and forward to it.

## Do and don't

- Do use an interface type for a parameter when any class with those methods will do.
- Do put shared code in a default method.
- Don't add properties to an interface. They do not compile.
- Don't write `trait`. Traits do not exist. Use default methods for shared code and `by` for shared data.
