Some objects stop being valid while the program runs. A row that was deleted from the database is
one example. A class that implements `Revocable` gets the method `revoke()`. To revoke an object
means to tell the program that the object is no longer valid. After that, every use of the object
throws an error. Passing, storing and comparing it with `==` do not throw.

## What happens after revoke()

| You write | The result |
|---|---|
| `$post->revoke()` | the object is removed from every `Core\ObjectMap`, `Core\ObjectSet` and `Core\Heap` |
| `$post->isRevoked()` | `true` |
| `$post->title`, `$post->title = 'x'` | throws `RevokedObjectError` |
| `$post->title .= '!'`, `isinit($post->title)`, `bump(inout $post->views)` | throws `RevokedObjectError` |
| `$post->publish()`, `$post?->publish()`, a `static` method called as `$post->make()` | throws `RevokedObjectError` |
| `$publish = $post->publish(...)` | no error |
| `$publish()` | throws `RevokedObjectError` |
| `"Title: {$post}"`, `echo $post`, `'x' . $post` | throws `RevokedObjectError` |
| `$post < $other`, `$post <=> $other` | throws `RevokedObjectError` |
| `foreach ($post as $line)` | throws `RevokedObjectError` |
| a method the class delegates to a property | throws `RevokedObjectError` |
| `clone $post`, `Core\Json::encode($post)` | throws `RevokedObjectError` |
| a `Core\Reflect` read, call or write | throws `RevokedObjectError` |
| `$post == $other`, `$post is Post`, `$post::class` | no error |
| `$post->revoke()` again | nothing happens |

A plain array, a property or a variable still contains the object. Only `Core\ObjectMap`,
`Core\ObjectSet` and `Core\Heap` remove it. `RevokedObjectError` is a `LogicError`. The page
[Error types](/syntax/errors/error-types/) lists it with the other error classes.

## Do and don't

- Do write `implements Revocable` on the class with no parent class. All its subclasses are then
  revocable too.
- Do keep objects that can be deleted in a `Core\ObjectMap` or a `Core\ObjectSet`. Then a deleted
  one is removed immediately.
- Do call `isRevoked()` when an object may already be revoked. It never throws.
- Don't declare `revoke()` or `isRevoked()` in your class. `Revocable` provides both.
- Don't expect a plain array to remove a revoked object. Remove it yourself, or use a `Core` collection.
