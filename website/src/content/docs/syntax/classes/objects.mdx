A variable that contains an object points to it. Assigning the variable, passing it to a method,
or storing it in an array does not copy the object. Novis frees an object when nothing points to
it.

## Do and don't

- Do use `clone` when you need a separate copy to change.
- Do use `?->` and `??` for an object that can be `null`.
- Don't use `object` when you know the class. A class type lets the compiler check every call.
- Don't expect `==` to compare properties. It checks if both sides are the same object.
