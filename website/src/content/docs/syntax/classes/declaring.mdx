A class describes a kind of object. It has properties, which contain the object's data, and
methods, which are functions that work on that data. Inside a method, `$this` is the object the
method was called on. An enum can be declared inside a class. See [Enums](/syntax/values/enums/).

<FeatureSection examples="lang/classes/declaring-a-class" heading="Declaring a class" id="declaring-a-class" />

## Do and don't

- Do write the visibility on every property, method and constant. Start with `private`. Change it to `protected` or `public` only when needed.
- Do use constructor parameters as properties when the constructor only copies its arguments.
- Don't name the constructor `__construct`. It does not compile. Name it `constructor`.
- Don't try to add a property that the class does not declare. It does not compile.
