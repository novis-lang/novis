## Do and don't

- Do implement `Stringable` when an object has one natural way to print it.
- Do implement `Comparable` when you need to sort objects or compare them with `<`.
- Do check the text in `parse` and throw `ParseError` when it is wrong.
- Don't expect `==` to compare the properties of two objects. Compare them yourself, or use `compareTo`.
