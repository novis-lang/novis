Sometimes the name of a property comes from a web address, a form or a JSON body. These three types
check that the name is right. A name written in the code is checked when the program compiles.

## Use this when a name comes from outside

Use `property<T>` for one property of one class. Use `propertyPath<T>` when the name goes through
related objects, such as `customer.address.city`. Use `string<K>` for a longer text that contains
names, such as a query condition.

## Do and don't

- Do convert a name from a request with `as ?property<T>`, and handle `null`.
- Do write a fixed name in the code, so the compiler checks it.
- Don't make a property public only so that a key can name it.
