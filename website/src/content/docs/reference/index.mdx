The reference has a page for every class and function in Novis, every setting in `nvs.toml`
and every `nvs` command. Each page shows how to use it, what it does and an example where
there is one.

- [Core classes](/reference/core/) lists every class in the standard library.
- [Configuration](/reference/config/) lists every block of `nvs.toml` and its keys.
- [CLI commands](/reference/cli/) lists every `nvs` command.

To learn how to write Novis code, use [Syntax](/syntax/).
