Returns the length of a string — counted in **grapheme clusters**, the units a reader
perceives as characters.

<MethodSignature id="Str.length" />

## Description

`length` answers how many characters a string holds. Because a Novis `string` is
guaranteed-valid UTF-8, there is no encoding to name and no `mb_strlen` twin: one
function, one correct answer.

The unit is the *extended grapheme cluster* (Unicode UAX #29): an accented letter
composed from two code points counts as one, and an emoji assembled from several code
points joined by zero-width joiners counts as one. This is the same unit `at`, `slice`
and every other position-taking member of `Core\Str` uses, so an index produced by one
member is always valid input for another.

If you need the size of the underlying data instead — for a `Content-Length` header, a
buffer, a storage quota — you are asking a question about bytes, not text: encode the
string and use [`Core\Bytes::length`](/reference/core/bytes/length/).

### Parameters

- **`$s`** (`string`) — the string to measure.

## Return value

Returns `uint`: the number of grapheme clusters in `$s`. The empty string returns `0`.

## Errors

None. Every `string` value is valid UTF-8 by construction, so there is no failure case.

<MethodChangelog id="Str.length" />

## Tips

- `Str::length($s) == 0` and [`Str::isEmpty($s)`](/reference/core/str/isempty/) answer the
  same question; prefer `isEmpty` — it says what it means.
- Migrating from PHP: code that used `strlen` to count *bytes* (checksums, wire
  protocols) should move to `bytes` values; code that used it to validate user-visible
  field lengths gets the behaviour it always wanted.
