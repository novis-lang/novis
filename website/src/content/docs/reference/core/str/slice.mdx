Extracts a part of a string, addressed by offset and optional length.

<MethodSignature id="Str.slice" />

## Description

`slice` is the one way to cut a string by position. Offsets and lengths follow the
range convention shared by every Core member that takes one — learn it once, apply it
everywhere:

- `$offset` names the first grapheme of the result; **negative counts from the end**
  (`-6` starts six graphemes before the end).
- `$length` limits how many graphemes are taken; **negative stops that many from the
  end**, and **`null`** (the default) runs to the end of the string.

Because positions are grapheme clusters, a slice can never split an accented character
or an emoji into broken bytes — the result is always valid `string` text. This is the
behaviour PHP's `substr` never had and `mb_substr` only approximated per code point.

### Parameters

- **`$s`** (`string`) — the string to slice.
- **`$offset`** (`int`) — where the slice begins; negative counts from the end. An
  offset past either end yields the empty string rather than throwing — a range is a
  *view*, and an empty view is a valid answer.
- **`$length`** (`?int`, default `null`) — how much to take: a count, a negative
  stop-before-the-end, or `null` for "to the end".

## Return value

Returns `string`: the selected part, possibly empty. The input is never modified —
every `Core\Str` member is pure.

## Errors

None. Every combination of offsets describes some (possibly empty) view of the string.
