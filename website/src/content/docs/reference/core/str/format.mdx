Builds a string from a template and arguments — `sprintf`, with the argument-mismatch
bug family turned into compile errors.

<MethodSignature id="Str.format" />

## Description

The template grammar is deliberately **`printf`'s**: the closed conversion list
`%s %d %u %f %e %g %x %X %o %b %%` with printf's flag, width, precision and `%1$s`
positional syntax — minus everything that reads ambient state (no locale-dependent
conversions). What you know from C, PHP or virtually any other language transfers
directly.

What is new is *when* it is checked: a literal template has its placeholder count and
types verified **at compile time**. `format("%d items", $name)` with a `string` argument
is a diagnostic naming the placeholder, not a runtime surprise. Six PHP functions
(`sprintf`, `vsprintf`, `printf`, `vprintf`, `fprintf`, `vfprintf`) collapse into this
one member plus an `echo`.

### Parameters

- **`$template`** (`string`) — the printf template. **This parameter is a taint sink**:
  a template that arrived from outside the process is refused at compile time, because a
  template is an instruction (`%999999999d` is an attack, not a formatting choice).
  Arguments are data and stay unrestricted; only the template must be trusted.
- **`...$arguments`** (`mixed`, variadic) — the values the placeholders consume, in
  order (or addressed positionally with `%1$s` syntax).

## Return value

Returns `string`: the filled-in template. Number formatting is locale-independent —
`%f` always uses `.` as the decimal separator. For human-facing digit grouping see
[`Core\Math::format`](/reference/core/math/format/).

## Errors

- A **literal** template with mismatched placeholders (wrong count, wrong type, unknown
  conversion) does not compile.
- A **tainted** template is refused at compile time (see above).
- A malformed template that only exists at run time throws `LogicError`: the template is
  the program's own grammar rather than input, so it lands on the "bug in the program" side
  of spec § 10's tree, exactly where a bad `Core\Time::parse` pattern does.
