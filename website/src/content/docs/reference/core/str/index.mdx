:::note[Strings are text, bytes are bytes]
A Novis `string` is real UTF-8 **text**, not just bytes: it is guaranteed valid,
indexed by the characters a reader sees, and no member here takes an encoding
argument. For binary data, use the [`bytes` type and `Core\Bytes`](/reference/core/bytes/) —
and cross between the two explicitly with [`Core\Encoding`](/reference/core/encoding/).
:::
