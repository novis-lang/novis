Everything in Novis's standard library is a member of a `Core\…` class — there are no
global functions. This reference is generated from the language's own specification and
registry, and it lists **only what the current toolchain implements**: every class and
member below exists and is callable today. Members that are specified but not built yet
appear here the day they land, automatically.
