Builds a new array by passing every value through a callback. Keys are preserved.

<MethodSignature id="Arr.map" />

## Description

`map` applies `$fn` to each element in insertion order and collects the results under
the **same keys** — over a list exactly as over a map. The element type of the result
is the callback's declared return type, so a
`map($users, fn(User $u): string => $u->name)` is an `array<string>` at the use site
with no cast.

Like every Core callback, `$fn` receives `($value, $key)` **and may declare fewer
parameters**: write `fn($v) => …` when you don't need the key, `fn($v, $k) => …` when
you do. This is what removes PHP's `ARRAY_FILTER_USE_KEY`-style flags and the
`…WithKey` twin functions — there is one `map`, and the callback's own signature says
what it wants.

Two things PHP's `array_map` did are deliberately absent:

- **Multi-array mapping** (`array_map($fn, $a, $b)`) — write a `foreach` over
  [`Arr::keys`](/reference/core/arr/keys/); a zip whose element type degenerates to a union
  would defeat the element typing that makes the rest of `Core\Arr` checkable.
- **`array_map(null, …)`** — the implicit zip has no equivalent for the same reason.

### Parameters

- **`$a`** (`array<T>`) — the input array. It is never modified — every `Core\Arr`
  member is pure, and the implementation reuses the allocation when nothing else holds
  the array, so purity costs nothing.
- **`$fn`** (`callable`) — called once per element as `($value, $key)`; its return
  value becomes the result's value under the same key.

## Return value

Returns `array<U>`, where `U` is the callback's declared return type — with the same
keys, in the same order, as the input.

## Errors

Whatever `$fn` throws propagates out of `map` unchanged; elements after the throwing
one are not visited.

## Tips

- Changing *keys* instead of values is [`Arr::mapKeys`](/reference/core/arr/mapkeys/);
  dropping elements is [`Arr::filter`](/reference/core/arr/filter/); folding to one value is
  [`Arr::reduce`](/reference/core/arr/reduce/).
- After a `map` over a keyed array, [`Arr::values`](/reference/core/arr/values/) renumbers
  into a list when the keys have served their purpose.
