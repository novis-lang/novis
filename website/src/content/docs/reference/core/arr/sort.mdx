Returns a sorted copy of an array. One member replaces `sort`, `rsort`, `asort`,
`arsort`, `usort`, `uasort`, `natsort`, `natcasesort` and `array_multisort`.

<MethodSignature id="Arr.sort" />

## Description

Everything PHP spelled as a function name is an option here:

- **Direction** is `{order: Order::Desc}` instead of the `r` in `rsort`.
- **Key preservation** is `{preserveKeys: true}` instead of the `a` in `asort`. The
  default discards every key and renumbers from `"0"` — on string keys exactly as on
  integer keys, because no Core member's behaviour depends on a key's type.
- **How elements compare** is `{by:}` or `{comparator:}` instead of the `u` in `usort`.

`{by:}` deserves the highlight: it takes a *key extractor* —
`{by: fn($user) => $user->age}` — which is what most `usort` callbacks were laboriously
emulating with `$a->age <=> $b->age`. Reach for `{comparator:}` only when the ordering
itself is custom; a natural sort, for instance, is
`{comparator: fn($x, $y) => Str::compare($x, $y, {natural: true})}`.

**The sort is stable**: elements that compare equal keep their relative order. PHP's
sorts were unstable until 8.0 and never promised it per function; here it is part of
the contract.

`{by:}` and `{comparator:}` **compose** — `by` decides what is compared and
`comparator` decides how, so a comparator given beside an extractor sees the
extracted keys. No combination of the options is refused.

### Parameters

- **`$a`** (`array<T>`) — the array to sort. Never modified; the sorted result is
  returned.

### Options

- **`by`** (`callable`) — key extractor; elements are ordered by the extracted keys'
  natural order.
- **`order`** (`Order`) — `Order::Asc` (default) or `Order::Desc`. Applies whichever
  of the three comparison modes is in effect.
- **`comparator`** (`callable`) — a two-argument comparison returning negative, zero
  or positive, like PHP's `usort` callback.
- **`preserveKeys`** (`bool`) — keep each element's key (`asort` behaviour). Defaults
  to `false`: discard keys and renumber.

## Return value

Returns `array<T>`: a sorted array with the same elements. A list in, a list out
(unless `preserveKeys` is set); the input's element type is preserved.

## Errors

Whatever `by` or `comparator` throws propagates out of the sort. Elements without a
natural order and no comparator are a compile-time type error, not a runtime one.
