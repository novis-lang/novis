Novis is one program, `nvs`. It checks, compiles, runs, tests and serves your code.

:::caution
Novis has no release yet. There are no prebuilt downloads and no package manager installs. To
get `nvs` today, you build it from source. The first release will have archives for Linux,
Windows and macOS.
:::

## What you need

You need Rust, which you install with [rustup](https://rustup.rs/). You do not need to choose a
Rust version. The repository has a file, `rust-toolchain.toml`, that names the version. `rustup`
installs that version the first time you build.

Some parts of the build compile C code, so you also need a C compiler:

<Tabs syncKey="os">
<TabItem label="Windows">
Install the Visual Studio Build Tools with the workload **Desktop development with C++**. The
`rustup` installer offers to do this for you.
</TabItem>
<TabItem label="Linux">
Install `git` and a C compiler. On Debian and Ubuntu, run `sudo apt install git build-essential`.
</TabItem>
<TabItem label="macOS">
Install the Xcode command line tools with `xcode-select --install`. They include `git` and a C
compiler.
</TabItem>
</Tabs>

## Build from source

<Steps>

1. Get the source code:

   ```sh
   git clone https://github.com/novis-lang/novis.git novis
   cd novis
   ```

2. Build `nvs`. This takes several minutes the first time.

   ```sh
   cargo build --release -p nvs-cli
   ```

3. Check that it runs. The first line of the output is the version.

   <Tabs syncKey="os">
   <TabItem label="Windows">
   ```powershell
   .\target\release\nvs.exe --help
   ```
   </TabItem>
   <TabItem label="Linux">
   ```sh
   ./target/release/nvs --help
   ```
   </TabItem>
   <TabItem label="macOS">
   ```sh
   ./target/release/nvs --help
   ```
   </TabItem>
   </Tabs>

4. Copy the program to a folder that is on your `PATH`. Then you can type `nvs` in any folder.

   <Tabs syncKey="os">
   <TabItem label="Windows">
   Copy `target\release\nvs.exe` to a folder such as `C:\Tools`. Then add that folder to the
   `Path` variable in **Settings > System > About > Advanced system settings > Environment
   Variables**.
   </TabItem>
   <TabItem label="Linux">
   ```sh
   sudo install -m 0755 target/release/nvs /usr/local/bin/nvs
   ```
   </TabItem>
   <TabItem label="macOS">
   ```sh
   sudo install -m 0755 target/release/nvs /usr/local/bin/nvs
   ```
   </TabItem>
   </Tabs>

</Steps>

## The commands you use first

| Command | What it does |
| --- | --- |
| `nvs run file.nvs` | checks a program, then compiles and runs it |
| `nvs check file.nvs` | checks a program and prints every error, without running it |
| `nvs test file.nvs` | runs the `#[Test]` methods in a program |
| `nvs serve file.nvs` | runs a web application until you stop it |
| `nvs fmt file.nvs` | rewrites a file in the standard layout |

`nvs help <command>` prints the help for one command.
