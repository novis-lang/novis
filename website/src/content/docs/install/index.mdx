Novis is one program, `nvs`. It checks, compiles, runs, tests and serves your code. You download
`nvs` or build it from source. Then you put it on your `PATH`.

The current release is <code>{version}</code>. Novis is {status}. Any release can change the
language, and Novis is not ready for production use.

## Download a release

Each release has an archive of `nvs` for each platform:

<ul>
  {archives.map((a) => (
    <li>
      {a.label}: <a href={a.url}><code>{a.file}</code></a>
    </li>
  ))}
</ul>

The file <a href={sums.url}><code>{sums.file}</code></a> has the checksum of each archive.
[Check a release archive](#check-a-release-archive) shows how to use it. The
<a href={releaseUrl}>release page</a> lists every file of the release.

<Steps>

1. Download the archive for your platform, and unpack it. The archive has a folder with `nvs` in it.

   <Tabs syncKey="os">
   <TabItem label="Windows">
   Right-click the `.zip` file and choose **Extract All**.
   </TabItem>
   <TabItem label="Linux">
   <Code lang="sh" code={`tar -xzf ${archiveFor('linux-x86_64').file}`} />

   On an ARM64 computer, use the file that ends in `linux-aarch64.tar.gz`.
   </TabItem>
   <TabItem label="macOS">
   <Code lang="sh" code={`tar -xzf ${archiveFor('macos-aarch64').file}`} />
   </TabItem>
   </Tabs>

2. Copy `nvs` to a folder that is on your `PATH`, as step 4 of
   [Build from source](#build-from-source) shows.

3. Check that it runs. The first line of the output is the version.

   ```sh
   nvs --help
   ```

</Steps>

## What you need to build from source

You need Rust, which you install with [rustup](https://rustup.rs/). You do not need to choose a
Rust version. The repository has a file, `rust-toolchain.toml`, that names the version. `rustup`
installs that version the first time you build.

Some parts of the build compile C code, so you also need a C compiler:

<Tabs syncKey="os">
<TabItem label="Windows">
Install the Visual Studio Build Tools with the workload **Desktop development with C++**. The
`rustup` installer offers to do this for you.
</TabItem>
<TabItem label="Linux">
Install `git` and a C compiler. On Debian and Ubuntu, run `sudo apt install git build-essential`.
</TabItem>
<TabItem label="macOS">
Install the Xcode command line tools with `xcode-select --install`. They include `git` and a C
compiler.
</TabItem>
</Tabs>

## Build from source

<Steps>

1. Get the source code:

   ```sh
   git clone https://github.com/novis-lang/novis.git novis
   cd novis
   ```

2. Build `nvs`. This takes several minutes the first time.

   ```sh
   cargo build --release -p nvs-cli
   ```

3. Check that it runs. The first line of the output is the version.

   <Tabs syncKey="os">
   <TabItem label="Windows">
   ```powershell
   .\target\release\nvs.exe --help
   ```
   </TabItem>
   <TabItem label="Linux">
   ```sh
   ./target/release/nvs --help
   ```
   </TabItem>
   <TabItem label="macOS">
   ```sh
   ./target/release/nvs --help
   ```
   </TabItem>
   </Tabs>

4. Copy the program to a folder that is on your `PATH`. Then you can type `nvs` in any folder.

   <Tabs syncKey="os">
   <TabItem label="Windows">
   Copy `target\release\nvs.exe` to a folder such as `C:\Tools`. Then add that folder to the
   `Path` variable in **Settings > System > About > Advanced system settings > Environment
   Variables**.
   </TabItem>
   <TabItem label="Linux">
   ```sh
   sudo install -m 0755 target/release/nvs /usr/local/bin/nvs
   ```
   </TabItem>
   <TabItem label="macOS">
   ```sh
   sudo install -m 0755 target/release/nvs /usr/local/bin/nvs
   ```
   </TabItem>
   </Tabs>

</Steps>

## Check a release archive

Each release has the file `SHA256SUMS` with the checksum of each archive. Each archive also has a
signed statement. It says that the release workflow of the Novis repository built the archive, and
from which commit.

These two commands check an archive. The first one needs the GitHub CLI, `gh`. Download
`SHA256SUMS` into the folder of the archive first.

<Code lang="sh" code={`gh attestation verify ${archiveFor('linux-x86_64').file} --repo novis-lang/novis
sha256sum --check --ignore-missing SHA256SUMS`} />

The first command checks the signed statement. The second command checks the archive against its
checksum in `SHA256SUMS`.

## The commands you use first

| Command | What it does |
| --- | --- |
| `nvs run file.nvs` | checks a program, then compiles and runs it |
| `nvs check file.nvs` | checks a program and prints every error, without running it |
| `nvs test file.nvs` | runs the `#[Test]` methods in a program |
| `nvs serve file.nvs` | runs a web application until you stop it |
| `nvs fmt file.nvs` | rewrites a file in the standard layout |

`nvs help <command>` prints the help for one command.
