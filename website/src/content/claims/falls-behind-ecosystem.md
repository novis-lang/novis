Laravel, Symfony, WordPress, npm's million packages, Stack Overflow answers for every
error message — none of that exists for Novis, and building it takes years, not
releases. If your problem is solved by an existing PHP or Node.js package today, using
that package is the pragmatic choice. Novis bets on a strong standard library to reduce
how much an application needs from an ecosystem, but a standard library does not replace
one.
