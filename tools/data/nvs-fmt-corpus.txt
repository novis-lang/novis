# Where the Novis code `nvs fmt` holds to its layout is, one entry per line.
#
# `tree <dir>` takes every `.nvs` file under the directory. `pages <path>` takes every ```nvs block of
# each `.md` and `.mdx` file that is the path or under it: the pages a reader sees the code on.
# `skip <path>  --  <why>` leaves out a directory or one file under either, which keeps the layout it has.
#
# Every `.nvs` file git tracks is under a tree, and `bun nv nvs-fmt --check` fails on one that is not.
# `crates/nvs-fmt/tests/identity.rs` fails on a file under a tree, or a block on a page, that the
# formatter would change, and `bun nv nvs-fmt` formats every such file and block, which is how a layout
# rule lands. A block the formatter refuses, such as a signature, is a fragment and stays as written.
# `crates/nvs-fmt/tests/corpus.rs` walks the trees with the skipped directories put back, and
# `bun nv verify`'s `nvs-fmt` step formats each new or modified file and page. `tools/nv/lib/
# nvs-fmt-corpus.ts` and `crates/nvs-fmt/tests/common/mod.rs` read this file.
