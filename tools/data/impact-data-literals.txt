# String literals that climb out of their directory and are data, one per line, each with why.
#
# `tools/nv/keys/escape.ts` makes a test binary wide when one of its sources holds a literal such as
# `"../x"`, because a test could open it relative to its working directory without `nvs_repo`. A
# literal listed here is one somebody read and found opens nothing in the tree outside the binary's
# own package, which its key holds whole: a path a pure function takes apart, an entry name in an
# archive built in memory, a path resolved against a scratch directory or inside the package, or an
# escape the code under test is expected to refuse. Every occurrence of the literal in
# that file is covered, so list one only when all of them are data. Only a climbing literal can be
# listed: a process or the working directory in test code, and `CARGO_MANIFEST_DIR` beside a climb
# anywhere, stay ways out.
# A line whose literal no longer climbs out of its file fails `bun nv verify`'s `test` step.
#
# `<file>  <literal as the source writes it>  --  <why it opens nothing>`
